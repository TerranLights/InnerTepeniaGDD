# Independent Historical Vignettes & Informational Sheets — Progress Tracker

**Started 2026-08-02.** Master index for a new city-history methodology, distinct from the existing
`[City]_Course_of_Events_Suggestions.md` files (sequential, but/therefore-linked, strictly pre-war Second
Interwar Period only). Per direct developer instruction: entries in this new pass are **fully independent** —
no entry depends on any other, none need be chronological, none need start at a city's founding or stop
before the Long Night War. Entries can land at any point in a city's history, including the present day. Some
are narrative vignettes (a specific incident, a specific person); others are drier informational sheets (a
pattern, a statistic, a standing fact). Both are valid. See `Byrd_Historical_Vignettes_and_Informational_Sheets.md`
for the approved pilot batch and format.

**Source material per city:** primarily each city's own `[City]_Physical_Infrastructure_Attributes.md`
(Methodology #1 attributes + Methodology #2 Cross-Referenced Extrapolation Findings — complete for all 35
outer cities + Amundsen Station), plus `Course_of_Events_Suggestions.md`, Local Cultures, Community
Infrastructure, and diaspora composition files where relevant. Same "reconstructed, not invented" discipline
as the rest of the project — every entry traces to something already established.

**Pacing:** 6 new entries per work session, cycling through cities within one subnet before moving to the
next. Expected to span multiple sessions/days given the total scope. Byrd's own subnet has only one city, so
it's being finished in place rather than treated as a full subnet rotation stop.

**File location per city:** `Background-Lore/Cities/[Subnet]/[City]/[City]_Historical_Vignettes_and_Informational_Sheets.md`
(sibling to that city's own `Course_of_Events_Suggestions.md`). Tri-Cities entries are split across their
three existing per-city folders but tracked as one combined regional total below.

## Milestones — Flag These the Moment They're Hit, Don't Let Them Slide

**At 12 entries for every single city/region in the country** (all 35 outer cities + Tri-Cities region +
Amundsen-Scott Station — Amundsen-Scott's own "12" checkpoint scales proportionally given its lower 20-30
target, developer's call on exact number when we get there) — **stop and notify the developer.** We then
build an "in-nation" connection spec sheet, cross-referencing what's accumulated across cities at that point.

**At 18 entries for every single city/region in the country** — **stop and notify the developer again.** We
then go back and add more inter-city connections to that same spec sheet, using the additional material
accumulated between the 12-checkpoint and the 18-checkpoint.

Neither milestone is close yet as of this writing (only Byrd/Halley/Neumayer have any entries at all, and
Byrd is the only one past 6). Tracked here so this isn't missed once every city's count actually starts
approaching 12 in later sessions.
