# City History — But/Therefore Enhancement Opportunities Tracker (Index)

**Purpose:** a second, dedicated pass through all 35 cities (following the completed Consistency
sweep — see `City_History_Consistency_and_Enhancement_Tracker.md`), specifically hunting for ways to
enrich each city's existing 10 numbered But/Therefore Course of Events chains, now that every city has
a completed Neo-Races Catalog (Phase 1c) and a full Megasheet triad to draw from. **Flag only** — no new
chains drafted, no texture woven into existing files. This is a punch list for a future pass.

**Split by subnet, 2026-07-17,** once the single combined file grew unwieldy — each subnet now has its
own file, linked below. This index file holds only the shared method and the progress checklist; per-city
flagged ideas live in the per-subnet files.

**Scope note (applies to every subnet file):** all flagged ideas are meant for *pre*-Long Night War,
Second Interwar Period content only — no war damage, no post-war material. Flagged ideas that would
require war-era framing are out of scope for this pass.

**Method, per city:**
1. Read the city's own Neo-Races Catalog (`Neo-Races-and-Cultures/[Subnet]/[City]/[City]_Catalog.md`) —
   the per-nation Cultural Iceberg findings.
2. Read the Megasheet (`Mega_Init`, and `Full_Extrapolation`/`Cross_Reference_Synthesis` where they add
   relevant texture).
3. Read `Course_of_Events_Suggestions.md` — the existing 10 chains — and spot-check 1-2 numbered stage
   files for tone/depth.
4. Look for enhancement opportunities through (at minimum) these lenses:
   - **Division of industry → history** — could a specific economic sector's own internal logic
     plausibly drive a but/therefore turn the existing chains don't currently use?
   - **Resident character cultures** — does a specific Significant/Notable-tier nation's own Cultural
     Iceberg findings (Catalog) suggest a character-flavor or conflict-flavor not yet present in the
     existing 10 chains?
   - **Real-world historical precedent** — is there a comparable real-world national/cultural struggle,
     with a genuinely non-ideal but functional resolution, that could ground a new chain the way the
     Megasheet's own Real-World Inspirations already do for civic identity?
   - **City personality / geography / geology → history** — does the Enneagram read, or a specific
     established geographic/geological fact, suggest a historical turn not yet dramatized?
   - **Other** — anything else that surfaces during the read that doesn't fit the above categories
     cleanly.
5. Log flagged ideas in the relevant subnet file, one entry per idea, citing the specific source detail
   it's grounded in. Don't invent texture that isn't traceable to something already established in the
   Catalog, Megasheet, or Specs/Local_Cultures files — per the same "reconstructed, not invented" standard
   the rest of this project holds itself to.
