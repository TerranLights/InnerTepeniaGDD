# Background Lore — Cities

Organized by subnet, then by individual city — 35 cities across 6 subnets (Halley 8, Janbogo 7,
Mawson 3, Mirny 8, Palmer 8, Byrd 1), mirroring the subnet/city structure already used in
`Local_Cultures/`, `City_Megasheets/`, and `City_Enneagram_Personalities/`. Amundsen Station is
excluded here, consistent with its established treatment as outside the 35-city framework.

**Each city's own folder is where that city's multiple candidate lore suggestions live** — different
proposed But/Therefore chains (see `to-be-integrated/But_Therefore_Lore_Design_Method.md`) for
whatever aspect of that city's history or culture is being developed, kept side by side for
comparison and review rather than committed to a single answer immediately. A city folder starting
with only a `.gitkeep` placeholder means no candidate lore has been drafted for it yet.

**Nothing in this folder is canon.** Once a suggestion is settled on, it gets promoted into that
city's own `Specs/`, `Local_Cultures/`, or Megasheet files — the same files the country-wide
integrity check already established as the source of truth — not left to live here permanently.
