# Background Lore

**What this is:** a workspace for developing new background lore — not itself canon until reviewed
and promoted into the main `Worldspace/` structure. Created 2026-07-15 to support ongoing city
(and, eventually, subnet- and nation-level) lore development using the "But/Therefore" method — see
`to-be-integrated/But_Therefore_Lore_Design_Method.md` for the full rules and schematics.

**Why a separate space:** each place gets *multiple* candidate lore suggestions, not one locked-in
answer per topic. This folder is where those candidates live and get compared before anything is
promoted into `Specs/`, `Local_Cultures/`, or the Megasheet layers.

---

## Structure

- **`Cities/`** — organized by subnet, then by individual city (35 cities across 6 subnets, matching
  the same subnet/city structure already used in `Local_Cultures/`, `City_Megasheets/`, and
  `City_Enneagram_Personalities/`). See `Cities/README.md` for the per-city convention.

Future top-level siblings of `Cities/` here are expected as work moves up in scale — subnet-level and
eventually nation-level background lore folders, per the developer's own stated direction.
