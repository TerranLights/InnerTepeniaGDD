# Failsafe / Hidden Ending Categories — Status Tracker

These are the ending scenarios not covered by the original four secret-ending categories (Pariah Failsafes, Minmax Endings, District Idolized Endings, Hidden Paths). Each represents a player state that could cause a softlock without a dedicated path.

All endings use the standard treatment:
- In-world trigger (physical object, location, or environmental state — no NPC-initiated triggers)
- Defined end moment
- One main negative effect on Concordia
- A handful of minor negative effects
