# ULM Records Archive

**Status: not canon, and not an input.** Nothing here is read, cited or used as a source by any ULM, CST or RWBEM
pass, cold or warm. It is kept because it may still be useful for something other than establishing a city
(`DEVELOPER_RULINGS_LOG.md` `DR-27`, 2026-10-01).

**What is here:** raw verification and run records, moved out of the working folders with their original
structure kept:

| Folder | Came from | Contents |
|---|---|---|
| `Test_Runs/` | `Worldspace/Locations-and-Levels/Universal_Location_Methodology/Test_Runs/` | The 14 ULM test-run folders (2026-08-30 to 2026-09-03) and three cold-run preps/traces |
| `City_Development_Passes/Mirny_Subnet/Davis/` | the Davis pass folder | `T8` reader files (`.t8_*`), `T8` round records (`*b_T8_Rounds_*`), the superseded single-reader Step −1 file |
| `City_Development_Passes/Mirny_Subnet/Mirny/` | the Mirny pass folder | `T8` reader files and round records for Pre-Trip through Step 3 |
| `City_Development_Passes/Mirny_Subnet/Zhongshan_Opus/`, `Zhongshan_Sonnet/` | each pass's `_archive_pre-redo_2026-09-10/` | the first passes, before the 2026-09-10 redo |
| `City_Development_Passes/Mirny_Subnet/Shirayuki/` | `Shirayuki/_Archive/` | the pass as it stood before the 2026-09-06 consolidation |

**Why they were moved rather than corrected:** these records contain station-heritage reasoning that the
2026-10-01 ULM files audit (`…/Cities/ULM_Files_Mistake_Audit.md`) found and that the rulings forbid. A citation in a
working file to one of these records (for example "`02b` L2069") resolves here, at the same file name.

**Excluded from:** the heritage check script (`Universal_Location_Methodology/Tools/check_founders_against_register.py`)
and, when it is next rebuilt, the knowledge graph.
