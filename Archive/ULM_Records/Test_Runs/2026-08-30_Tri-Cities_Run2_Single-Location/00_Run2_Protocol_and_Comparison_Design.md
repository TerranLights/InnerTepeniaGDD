# Run 2 — Protocol and Comparison Design

**TEST RUN 2. NOT CANON.** Nothing here is written to the official city files.

**Same three subjects as Run 1** *(Zhongshan · Sinheung · Shirayuki, pre-unification, three separate cities)*.
**Different methodological layout**, so the two runs can be compared.

**Observations from both runs go into the single shared file:**
`../2026-08-30_Tri-Cities/OBSERVATIONS_and_Methodology_Findings.md`

# 1. What changed between the runs

| | **Run 1** | **Run 2** |
|---|---|---|
| **Layout** | **Co-write** — three cities in one document, profiles built side by side | **Three separate passes.** Each city written alone, start to finish, before the next begins |
| **Methodology version** | Pre-incorporation | **Post-incorporation** — commit `0b226a9`, single-location-first |
| **Differentiation against** | The two cluster neighbors | **The full 35-city outer set**, per `04` III.3 "large set" |
| **Circularity rule** | Provenance-scoped *(the loose version)* | **Kind-scoped** — prior culture-pass conclusions inadmissible |
| **Canon read order** | Ad hoc | **Step 0.4 triage** — specs → symbols → census → founding → *culture files last* |
| **Quantitative claims** | Local comparison | **z-scored against the full set** |
| **Configuration** | Undeclared | **Declared exceptional**, with the dependent findings named |

**The question this comparison answers:** *does building one location at a time produce a better location than
building three at once?* — and, separately, *what does the co-write buy that is genuinely worth its cost?*

---

# 2. ⚠ The contamination problem, declared rather than papered over

> **A re-run by the same author who remembers the first run is not independent, and no protocol makes it so.**

**I cannot un-read Run 1.** Its findings — the retention spread, the origination deficit, the pull/push
reading — are in working memory and will inevitably shape what I notice. **Claiming a clean-room re-derivation
would be false**, and it would be exactly the self-flattering audit failure this project has measured five
times.

**So the honest protocol:**

1. **Every finding in Run 2 is tagged** — **`[re-derived]`** *(the inputs were re-run and the conclusion
   followed again)* · **`[recalled]`** *(carried over from Run 1 without independent support)* ·
   **`[new]`** *(not present in Run 1 at all)*.
2. **`[new]` findings are the only clean evidence** about whether the single-location layout is better, since
   they cannot have come from Run 1.
3. **Novelty against *canon* is still verified by scan** — that check is unaffected by contamination, because
   canon does not change between runs.

**What the comparison can therefore establish, honestly:** whether the single-location layout **surfaces
material the co-write missed**, and whether it **loses anything the co-write had.** Both are visible in the
`[new]` set and in what Run 1 has that Run 2 does not.

**What it cannot establish:** whether a genuinely naive single-location pass would have reached Run 1's
findings. **That would need a different author or a cold session**, and is logged as a limitation.

---

# 3. Order of work

**Deliberately sequential, and deliberately in an order that puts the hardest case first.**

1. **Zhongshan** — written alone, complete, before Sinheung is opened.
2. **Sinheung** — written alone. May read Zhongshan's *attributes* as canon; **may not read Run 2's Zhongshan
   conclusions** as input, per the kind-scoped circularity rule.
3. **Shirayuki** — same.
4. **Cross-comparison, last** — differentiation and collision checks, run *after* all three exist rather than
   during, which is the ordinary `04` Part III procedure.

**This ordering is itself part of the test.** Run 1 built the comparison table *first* and derived the cities
from it. **Run 2 builds the cities first and the comparison last** — which is what a real production sequence
would look like, since in practice a location is written months before its neighbor.

# 4. Standing declarations for all three passes

**Configuration: EXCEPTIONAL.** These three cities are 0.3–8 km apart, share one airport, one highway
tri-junction, one founding act, and the same three national populations at rotating tiers. **They are the
highest-relationality set in the project.** Findings that depend on that property are marked, so a later reader
can tell which technique transfers to an ordinary isolated city.

**Written: ALONE** — each pass is a single-location pass. No co-writing.

**Frame: pre-unification, Orbital Era, pre-war.** Three legally separate cities. *(The post-unification
single-city pass remains a separate REQUESTED document.)*

**Reserved, and not to be foreclosed:** the unified city's name · whether "Alternative Culture" belongs to
Shirayuki alone or the whole cluster · the disposal-of-the-dead mechanism · all proper names of people.
*(Updated 2026-08-30: **Sinheung's name is now official and is no longer reserved.**)*
