# Hermes Research

A setting where the AI agent Hermes is able to write data resulting from research, both throughout the web as well as through/across eBooks (PDF, EPUB, etc).

*This does **not** "replace" Claude.* It merely *supplements* Claude's research, derivation, synthesis, and contemplation.

### Purpose Overview

The general principle behind including Hermes in the process is that Hermes would do a substantial amount of the mechanical-level research, as a way of offloading Claude's burden, so that Claude will be able to spend more time doing full, proper data-processing on the information available.

### Basic Summary

##### Hermes
- finds wherever possible

##### Claude
- finds where necessary
- fills in gaps
- expands, extrapolates, rounds out
- thinks whenever it can

## Summation

Claude is still the main AI overseer of the project (2nd only to the Lead Developer and repo-owner). Hermes is present as a supplement to research in order to ease part of the tedium burden from Claude.
