- [x] **De-stacking method applied to all city Per-Nation Breakdown tables — 2026-07-05**
  The developer noticed the raw share-weighting methodology inevitably produces "stacks" of same-tier nations with identical percentages (e.g. Zukelli's six Significant-tier nations all showing exactly 7.9%) — a visibly artificial pattern. Developed and applied a randomized de-stacking method, tested first on Zukelli alone and approved before being run project-wide:
  1. Within each tier of 2+ nations, randomly select half (rounded up) as "adjustment targets"; the rest form that tier's "subtraction pool."
  2. For the top tier (Primary), each chosen nation's addition = a random 5–10% of its own tier percentage.
  3. For every other tier, each chosen nation's addition = a random 10–25% of the gap between its own tier percentage and the percentage of the tier immediately above it.
  4. Each addition is mirrored by an equal subtraction from a randomly chosen, not-yet-used member of that same tier's subtraction pool (cycling with reuse only when a tier's pool is smaller than its chosen set, e.g. a 2-nation Primary tier with 1 chosen/1 unchosen absorbing more than one addition).
  This preserves each tier's total percentage and relative ordering (no nation crosses into a different tier's range) while eliminating identical-looking figures. Applied to all 35 cities' "Per-Nation Breakdown" tables; Zukelli's originally-shown, developer-approved values were locked in as-is rather than re-rolled. Verified afterward: no nation ended up at 0% or negative, and every city's percentages still sum to ~100%. **Bug caught mid-pass:** a fresh draw for Dome Fuji's 9-nation Significant tier produced a real tier crossover (a Significant-tier nation dropping below several Notable-tier nations, since multiple subtractions piled onto the same small unchosen pool) — none of the other 34 already-written cities had this problem, but it's a real possibility of the method whenever a tier's unchosen pool is small relative to its chosen set. Fixed via rejection sampling (re-roll until no tier crosses another's range) rather than changing the underlying method; added the same rejection check as a permanent safeguard for any future re-rolls.
