# [Character Name] Questline Notes

High-level designer notes, branching ideas, integration with main story, etc.

**Applicability note:** this folder is primarily relevant for Still-Present – In-Game / recruitable
companions, who get a personal questline and (per `Companion_System.md`) a romance arc. For
Past-History – Known to Tepenians or Off-World or MIA characters, this folder will usually stay empty or
unused — they're referenced through lore (terminal entries, journal/log entries, NPC dialogue and rumors)
rather than through an active in-game questline. Leave it in place regardless; it costs nothing to have an
unused folder, and it means nothing has to be added back later if a character's status ever changes.
