# Doll Character Spec — Fill-In Sheet Template

**What this is:** a reusable version of the worksheet built for Maggie Aarden
(`Still-Present_-_In-Game/recruitable/Maggie Aarden/Companion_and_Romance_Questline_Design_Inputs.md`),
generalized so it can be copied into any Doll's own folder as a starting point for gathering her personal
details. It's organized as a set of questions with a short rationale under each — fill in whatever you have a
clear sense of under "Your answer," and leave the rest as `TBD`. Nothing here needs to be answered all at
once, and nothing here needs to be answered in order.

**How this maps onto the existing structure:** this sheet's sections feed directly into the standard Doll
folder skeleton (`README.md`, `Personal_Background/PreWar_History.md`, `Personal_Background/Relationships.md`,
`Personal_Background/Loyalties.md`, `Personal_Background/Timeline.md`, `Personal_Background/War_Experiences.md`,
and — if she turns out to be recruitable — `Questlines/Personal_Questline_Summary.md`). You don't need to write
in that structured format yourself; write in plain prose here, in your own words, and the structured files get
built from your answers afterward.

**Where to put it:** copy this file into the Doll's own folder (alongside her `README.md`) once you're ready
to start developing her, the same way Maggie's own worksheet lives in her folder. Not every section applies to
every Doll — a background-only or off-world/MIA character, for instance, may not need Section 10 (Role in the
Story / Companion Potential) filled out in any depth.
