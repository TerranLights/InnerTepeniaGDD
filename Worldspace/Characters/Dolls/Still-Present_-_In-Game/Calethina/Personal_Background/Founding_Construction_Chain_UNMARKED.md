# Calethina's Construction & Shipping Chain — UNMARKED LORE

**Design status, confirmed 2026-07-12:** this content is deliberately unmarked, following the same precedent as the Cradle network ([[feedback_cradle_unmarked_lore]]). **No quest markers, no logs, no quest tracking, no pointers, no XP.** It exists to be found by a sufficiently diligent, patient, curious player piecing together records scattered across real locations — not to be surfaced through any UI, journal entry, or guided objective. Treat any implementation of this content the same way the Cradle is treated: pure optional background lore.

See `Questlines/Substrate_Transfer_and_Embodiment_Design.md` for how this fits into her overall design.
