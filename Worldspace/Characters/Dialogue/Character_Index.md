# Dialogue — Character Index

**What this is:** a running log of exactly which characters currently have a folder under this `Dialogue/`
tree — not a plan or a to-do list (see `Dialogue_TODO.md` for that), purely a record of what physically exists
right now, so it's never necessary to `find`/`ls` the whole tree just to answer "is So-and-so's dialogue folder
already started?"

**Maintenance rule:** whenever a new character folder is created under `Companions/`, `Non-Recruitable_Romanceable/`,
or `Named_NPCs/`, add one row here in the same pass. Whenever a sheet is added to an existing character's folder,
update that row's Sheets Present list. This file should never drift out of sync with the actual folder tree — if
it ever does, trust the folder tree and fix this file, not the other way around.

**Schema conventions used below:** see `../../to-be-integrated/Dialogue_Tree_Spreadsheet_Setup_Guide.md`'s
"Inner Tepenia's Own Extensions to This Format" section for the full column/naming/folder standard this index
assumes.
