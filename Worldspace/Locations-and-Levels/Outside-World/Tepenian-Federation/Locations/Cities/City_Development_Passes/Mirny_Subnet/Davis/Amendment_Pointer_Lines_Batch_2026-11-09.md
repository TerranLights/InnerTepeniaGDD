# Davis: the proposed pointer lines and the other correction lists, 2026-11-09

**Status: PROPOSED. NOTHING IS APPLIED. No pass file, spec, source or check file is changed by this page.** Written at the developer's request after the Davis walkthrough of 2026-11-09. Built by script from section 4 (the docket) of the seven Davis amendment pieces; the lines below are cut from the pieces' tables, not retyped.

**What a pointer line is.** One line at the END of an old pass file, so no cited line moves (`Amendment_Layer_Rules.md` rule 3), sending its reader to the amendment. Applying one is a pass-file edit: it waits for the developer's word, `DR-101` is reconciled at that point (`DR-116` item 2), and a second reader reads each line against the whole finding it touches before it is committed (rule 4). **Corrections themselves are never written into a pass file; a pointer line only says where they are.**
