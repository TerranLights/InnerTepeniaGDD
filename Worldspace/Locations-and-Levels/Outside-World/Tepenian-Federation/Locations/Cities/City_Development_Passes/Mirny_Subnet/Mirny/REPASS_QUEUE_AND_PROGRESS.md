## Rules for every firing (binding)
1. **Run `date` first.** ULM work runs **only 05:00–14:59** (developer, 2026-11-04: "we go until 3 pm"). Outside that window: say "outside window" and stop. There is **no earlier cutoff** for starting a unit; start any unit that can plausibly finish, and at 14:59 stop and save the state in the progress table below ("IN PROGRESS: <where it stopped, files written>"). Never work after 14:59. No waiver exists for this run.
2. **Take the first unit that is not DONE and not BLOCKED.** If one is IN PROGRESS, resume it from its saved state. One unit per firing.
3. **Before the first unit of a session, read `Worldspace/Locations-and-Levels/Universal_Location_Methodology/00_RUNBOOK.md` in full** (repo `CLAUDE.md`: mandatory before any location-culture work), then `DR-74`, `DR-56` and the Mirny amendment files listed in the handoff section 5. Record "runbook read <date> <time>" in the table.
4. **Mirny only.** Never open another city's pass folder or culture files (ONE LOCATION law). Shared sources, the Mirny spec, census rows, Register, relationship entries naming Mirny, and Mirny's own folders are fine. This session is therefore contaminated for any other city's run: **Casey's run needs a different, fresh session.**
5. **Procedure for a piece (`DR-74`):** trimmed reading list from the second piece on (`Tools/make_t8_required_list.py`, `Tools/build_t8_standard_entries.py`), **three independent Opus readers** (`Agent` with `model: "opus"`, each given the same frozen brief, none told the others' answers; they do not use graphify and disregard the graphify hook, repo `CLAUDE.md` exception) → Round 2 `Tools/triple_read_verify.py` (the `EXEMPT:` defect is fixed) → Round 3 cross-check by `SendMessage` (a deferred tool: load it with ToolSearch) → merge by `M-246` → quotation triage (`Tools/quotation_audit.py`) → American English sweep → write the piece as NEW files in this folder, named like the earlier ones (`Amendment_Rederivation_<piece>_<date>.md` and `…b_T8_Rounds.md`; scratch reader files `.t8_amend_<piece>_*`). Previous pieces are the pattern: P6, P7, P8, P2c in this folder. **Paste raw tool output into the record; never summarize a scan.**
6. **Decisions.** Do not stop to ask. For every question that needs the developer, add an entry to the decisions file (format in that file), in plain language with the facts and a recommendation. **Continue the unit on the recommended answer**, mark the piece "PROPOSED" and each affected finding "PROVISIONAL (DEC-nnn)". A later piece built on an unclarified piece says so in its provenance.
7. **Never edit a pass file.** Never commit or push. No web searches unless a unit says so (none do). Do not invent worldbuilding where no ruling or source supports it: write the gap to the decisions file and mark the unit BLOCKED if it cannot proceed.
8. **After the unit:** update the progress table (status, start and end time, files written, decisions raised) and one line in `Research_Logs/ULM_Runs_Casey_Then_Mirny_Handoff_2026-11-03.md` section 5 if the order changes. **When every unit is DONE or BLOCKED:** write `REPASS_COMPLETE_<date>.md` here (a summary and the list of decisions raised), then call `CronList` and `CronDelete` on the repass job.
