# Denison — Datasheet · Step 8 (The Review Panel)

> **Tier U — the panel-position roster and disposition definitions, fixed corpus-wide.**

Citation: `Corpus_Reference_Sheets/Review_Panel_Full_Text_Quick_Reference.md`, in full — carries
`Disciplines/00f_Review_Panel.md`'s panel-position roster (Six Flat Archetypes plus the mandatory
Passer-Through and Neighbor, and the Lover faculty's question every time) plus the six disposition
definitions.

| Disposition | Definition |
|---|---|
| accepted | Write it |
| noted | Real but deferred; say why |
| rejected | Say why; a position being wrong is a normal and useful result |
| refereed | Two panelists conflict and both are right: state what each is right about, where each overreaches, and write the finding as the settlement |
| unmet | The location knowingly protects this and would refuse to surrender it — diagnostic of the place's self-knowledge |
| declined | The pass refuses the objection on anti-homogenization grounds, but the location has no awareness with which to protect anything; written as characterization, never counted as self-knowledge |

*(Definitions per `Corpus_Reference_Sheets/Review_Panel_Full_Text_Quick_Reference.md` §"The six dispositions, defined in full".)*

SPECIFIC TO THIS PLACE with something that could be true anywhere?"*
