# Scripts behind `Esperanza_Extent_Research_2026-11-03.md`
Python 3 with numpy, rasterio, pyproj, scipy (installed in a throwaway virtual environment). Public data only: ITS_LIVE (its-live-data.s3.amazonaws.com), PGC REMA (pgc-opendata-dems, read unsigned with `AWS_NO_SIGN_REQUEST=YES`), BAS Bedmap3 (a 361 MB file downloaded to its own folder).
Run order: `read_v.py` (window of velocity and masks) -> `analyze.py` (speeds by distance ring and box) -> `read2.py` and `analyze2.py` (version check, seasonal amplitude, trend) -> `rema.py` (elevation window) -> `map2.py` (maps and slope) -> `area.py` (speed x slope areas) -> `thick.py <bm3_thickness.tif> <folder holding the .npz files>` -> `channel2.py` (gap to James Ross Island).
The scripts write and read small `.npz` files in the current folder; they were run from a scratchpad folder, so paths inside may need a change. Esperanza Base point used: 63°23.9'S 56°59.8'W (own recall; the fetched pages gave 63°23'S 56°59'W for the bay).
