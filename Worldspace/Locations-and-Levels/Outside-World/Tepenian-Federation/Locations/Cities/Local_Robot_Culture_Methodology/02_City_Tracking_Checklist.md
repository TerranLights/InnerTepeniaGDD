# Local Robot Culture — City Tracking Checklist

Mirrors `Local_Cultures/`'s own subnet folder structure exactly, confirmed directly against that folder's
actual contents 2026-08-10 (not reconstructed from memory). 35 cities + Amundsen Station = 36 entries total.

**Status values:** Not Started / Draft (pending review) / Complete (developer-reviewed and accepted).

**One legitimate non-entry, not a city:** `Local_Cultures/Mirny_Subnet/Tri-Cities_Region.md` is a regional
rollup file covering Zhongshan/Sinheung/Shirayuki together, not a standalone city — excluded from the checklist
below; the three cities it covers are each tracked individually.

**Symbol-system correction pass, 2026-08-10.** Prompted by a developer request to double-check Janbogo, this
surfaced a real, systemic gap: `to-be-integrated/city-symbol-pairs.md` pairs every one of Tepenia's 35 outer
cities with two *independent* symbols — a Solar symbol (9 planets + the Asteroid Belt/Decentralization, 10
slots) and a Robo-Element (8 slots), each chosen on its own merits, not a matched pair. Six already-drafted
files had errors against this: Janbogo, Mirny, and Shirayuki each proposed a fresh Element without checking the
file at all, and all three proposals conflicted with the real pick; Zhongshan and Byrd also skipped the check
but happened to land on the right Element by coincidence, missing the Solar symbol half and wrongly framing the
result as a "first-ever proposal"; Mawson, Dome Fuji, and Sayowa checked correctly but mislabeled the two-slot
pairing as a "dual Elemental" case. All six corrected in place — see each file's own Reference Note — and the
methodology doc (`00_DRAFT_Input_Categories_and_Approach.md`, Input Category E) rewritten so every remaining
city gets checked against both slots from the start. Separately, Rothera's own long-open Solar symbol was
confirmed as the Asteroid Belt, with total certainty, per direct developer instruction — `city-symbol-pairs.md`
updated directly.
