# Tepenia Airport Network

Which Tepenian cities/locations retain functional airports in the post-war/present-day setting. A short, deliberately curated list — confirmed 2026-07-06 directly from the developer's own "Tepenian Airport Map" reference image (`Reference/Images/Maps/Tepenian airport and flight map.jpeg`). Every other city, including several with real-world Antarctic stations that do have airstrips today, is **highway-only** in Tepenia — this list does not track 1:1 with the real-world research pass in `Reference/Real-World/Stations/Antarctic_Stations_With_Airstrips.md`, which should be treated as background reference only, not a predictor of Tepenia's own network.

## Everything Else Is Highway-Only

Every other Tepenian city — including ones whose real-world station has a genuine airstrip today (Amundsen Station, Belgrano, Byrd, Casey, Concordia, Davis, Dome Fuji, Dumont d'Urville, Fort McMurdo, Halley, Kunlun, Lazar, Mawson, Neumayer, Palmer City, Princess Elisabeth, Sanay, Sayowa, Scott, Vostok, Juan Carlos, and others) — has no functional airport in Tepenia. Access to these cities is via the highway network only (`Locations/Infrastructure/Highways.md`).
