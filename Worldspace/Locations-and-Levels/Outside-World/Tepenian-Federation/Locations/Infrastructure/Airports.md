# Tepenia Airport Network

Which Tepenian cities/locations retain functional airports in the post-war/present-day setting. A short, deliberately curated list — confirmed 2026-07-06 directly from the developer's own "Tepenian Airport Map" reference image (`Reference/Images/Maps/Tepenian airport and flight map.jpeg`), with locations refined 2026-07-07 against a companion highway-overlay version of the same map, which shows each airport marker sitting directly on the highway network — also mirrored into this same folder as `Tepenian airport and flight map - highway overlay.jpeg` for convenience. **⭐ Updated 2026-09-02: the developer revised BOTH map images to add Byrd** *(see its row below)*. **The table below now reconciles 1:1 with the maps — ten markers, ten rows:** Zukelli/Janbogo · Mirny · Tri-Cities · Troll · Rothera · Marambio · Machu Picchu · Mountain Pass · Belgrano · Byrd. Every other city, including several with real-world Antarctic stations that do have airstrips today, is **highway-only** in Tepenia — this list does not track 1:1 with the real-world research pass in `Reference/Real-World/Stations/Antarctic_Stations_With_Airstrips.md`, which should be treated as background reference only, not a predictor of Tepenia's own network.

## Everything Else Is Highway-Only

Every other Tepenian city — including ones whose real-world station has a genuine airstrip today (Amundsen Station, Casey, Concordia, Davis, Dome Fuji, Dumont d'Urville, Fort McMurdo, Halley, Kunlun, Lazar, Mawson, Neumayer, Palmer City, Princess Elisabeth, Sanay, Sayowa, Scott, Vostok, and others) — has no functional airport in Tepenia. Access to these cities is via the highway network only (`Locations/Infrastructure/Highways.md`).
