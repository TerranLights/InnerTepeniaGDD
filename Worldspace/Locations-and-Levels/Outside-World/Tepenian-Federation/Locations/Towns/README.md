# Towns

**What this folder is.** The developer's **towns idea** (`DR-52`, 2026-10-03): real Antarctic stations on **stable** ground that are **not already declared cities** become lightly developed Tepenian towns (a fuller country; DLC places between cities; *Southern Lights*; a path from the coast to Ariun Nuur, Kunlun and Dome Fuji).

**Start here:** `Towns_Data_Pass_Findings_and_Handoff_2026-10-04.md` (the findings, the rulings that govern this work, and what needs web research next).

**Data:** `Data/Real_Station_Inventory_Raw.csv` (524 locations), `Data/Real_Station_Inventory_Crossmatched.csv` (adds the nearest city and the nearest highway), `Data/Real_Station_Inventory_Method_and_Log.md`, `Data/scripts/`.

**Status:** data collected and cross-matched; **stability not yet tested** (ice velocity and bedrock depth); **no town has been named or characterized.** Town character is designed only 05:00 to 14:59; data collection is any hour.
