# ⭐⭐⭐ MODE: **WARM. ALL 38. Developer ruling, 2026-09-05.**

> **"Cold runs are ideal for TESTING the methodology; warm runs are ideal for PROCURING RESULTS."**
> *— the developer's own finding from the test runs, and now the standing mode for this entire run.*

⭐ **`Run_Modes_Warm_and_Cold.md` already defines them exactly this way** — *"COLD — the validation
instrument" · "WARM — the production instrument"* — **and records what learning it cost: *"Runs 12, 13 and 14
died inside it — three consecutive runs, no phase written."*** ***The evidence cold mode exists to produce is
already banked. It does not need producing again.***

## ✅ What a warm run DROPS — none of it is required

**The memory blackout (`Step −3`) · the reader briefs (`§C.2`) · the pre-contamination review and its pins ·
the vector-1 skip ranges and shape sweep (`Step −2`) · the alias-set build.**
⭐ **And `graphify` is available** — *`CLAUDE.md`'s prohibition is binding **only** during a cold run, and says
so: "Not binding otherwise."*

## ⛔⛔ WHAT DOES NOT RELAX — and this is the whole discipline of a warm run

| | |
|---|---|
| ⭐⭐⭐ **ANTI-CONVERGENCE** | ***"Never carry one location's answers into another. If two places produce similar-shaped answers to the same technique, at least one of them is wrong."*** **Binds in BOTH modes, always.** *Cold mode drops anti-contamination and keeps THIS* |
| ⛔ **OTHER CITIES STAY CLOSED UNTIL STEP 6** | *Not for quarantine — **so that Gate 6 has something independent to test.*** **Open them early and the gate tests nothing, because the pass will already have been shaped by them.** ⚠ **Easiest rule to lose in a warm run, precisely because everything feels open** |
| ⛔ **THE MANDATED READ ORDER** | `Step 0.4` — *"the whole discipline in warm mode"* |
| ⛔ **DECLARE THE MODE IN THE FRAME BLOCK, PER CITY** | *"A warm run is honest. **A 'semi-cold' run is a warm run wearing a cold run's credibility.**"* |
| ⚠ **Until Gate 6 fires, run all four `04` Part III.4 substitutes and SAY SO** | *own earlier states · nearest analogous location at another scale · real-world comparables · the generator-conflict method* |
