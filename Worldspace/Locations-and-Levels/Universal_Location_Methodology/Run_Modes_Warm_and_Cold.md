# RUN MODES — WARM and COLD, defined

**Established 2026-09-04, developer ruling.** ***"I may have to do 'warm runs' on cities, with the caveat to
ignore all other cities."***

> ## ⚠ LAYER: **PROJECT.** Companion to `00_RUNBOOK.md`, not to the universal layer.
> **`01`–`05` are unaffected by this file.** ***Both modes run the identical spine, the identical eleven
> phases and the identical seventeen gates.*** **Only the ADMISSIBLE INPUT SET differs, and one gate moves.**

---

# 0. THE DISTINCTION THIS FILE EXISTS TO MAKE

**The quarantine was doing TWO jobs, and they had been fused into one instrument:**

| Job | Protects against | Needed for |
|---|---|---|
| **ANTI-CONTAMINATION** | ***the deriver already knowing the answer*** — reading this city's own prior conclusions and then "deriving" them | ⭐ **proving a derivation was INDEPENDENT.** A validation property |
| **ANTI-CONVERGENCE** | ***carrying one city's answers into another*** — thirty-seven places coming out alike | ⭐⭐ **the QUALITY of the set.** A correctness property |

> ### **A WARM RUN DROPS THE FIRST AND KEEPS THE SECOND.**
> **`Cultural_Synthesis_Techniques.md`'s governing rule is the second one:** ***"Never carry one location's
> answers into another. If two places produce similar-shaped answers to the same technique, at least one of
> them is wrong."*** **That rule binds in BOTH modes and is never relaxed.**

---

# 1. THE TWO MODES

## ⛔ COLD — the validation instrument

**Everything conclusion-tier about the subject is withheld until Step 7.** **Requires: the memory blackout
(`STEP −3`), the reader briefs (`§C.2`), a `CONFIRMED` pre-contamination review with both pins verified, the
vector-1 skip ranges and the shape sweep (`Step −2` 1a/1b).**

| | |
|---|---|
| **Proves** | ⭐ **that the derivation was independent** — the M-35 evidence class *(a cold pass reproducing a withheld sheet's central finding, near-verbatim, before that file was opened)* |
| **Also buys** | ⭐ **canon audit.** `04` Part IV: one cold read surfaced **four live canon errors** that had survived repeated review |
| **Costs** | **the whole quarantine apparatus.** ***Runs 12, 13 and 14 died inside it — three consecutive runs, no phase written*** |

## ✅ WARM — the production instrument

**Everything about THIS city is open, in the mandated read order.** **Conclusion-tier material about EVERY
OTHER city stays closed until Step 6.**

| | |
|---|---|
| **Proves** | **nothing about independence — and does not need to.** *That evidence is already banked* |
| **Buys** | ⭐ **a better city.** *A warm pass with complete inputs beats a cold pass with starved inputs* |
| **Costs** | **the evidence class, and cold-read-as-canon-audit** *(recoverable mechanically — see §6)* |
| **Drops** | **the memory blackout · the reader briefs · the pre-contamination review · the pins · skip ranges.** ***None of these is required for a warm run*** |

# 2. ⛔⛔ THE ONE RULE THAT DOES NOT RELAX

> # **THIS CITY'S OWN CULTURE MATERIAL IS READ LAST, AND READ AS A CHECK.**
> **`05` §6.1 · `00_RUNBOOK.md` Step 0.4 item 6.**

**In a COLD run the quarantine physically prevents opening it. IN A WARM RUN NOTHING DOES.** ***This is the
single point where a warm run can silently destroy its own value.***

**`05` §6.1, verbatim:** *"Conclusions are read LAST, and read as a CHECK. After the pass produces its own
findings, compare. **A match is corroboration. A mismatch is a finding site.** Consulted at the start they are
contamination; consulted at the end they are evidence."*

### The mandated read order — `Step 0.4`, and it is the whole discipline in warm mode

| # | Read | |
|--:|---|---|
| **1** | specs / physical facts | |
| **2** | symbol assignment | |
| **3** | composition, census, **and population change across snapshots** | |
| **4** | founding and events | |
| **5** | the sibling set's differentiation instrument, if one exists | |
| **6** | ⛔ **LAST — this location's own completed culture material** | ***as a CHECK, never as an input*** |

> ***A pass that reads `<City>_Full_Extrapolation.md` before deriving has planted its own seed and will find
> it.*** **`05`: the result is *"perfectly coherent and contains no information."*** **For a foundation layer
> that is indistinguishable from good work, which is exactly what makes it dangerous.**

### ⚠ And `06_Worked_Example_Provenance.md` still applies in warm mode
**Required reading may carry THIS city's own worked example.** **Reading it at `Step 0.2` violates the read
order before the pass has begun.** **Check `06` for the subject, and treat any hit as read-last material.**

# 3. WHAT IS ADMISSIBLE IN A WARM RUN

| ✅ OPEN from the start | ⛔ CLOSED until Step 6 |
|---|---|
| **All of this city's attributes** — spec, climate, founding, network position, symbol members | ⛔ **Other cities' CULTURE files** |
| **Census, composition, Division-of-Industry figures** *(all cities — these are attributes)* | ⛔ **Other cities' `Full_Extrapolation` / `Mega_Init` / robot-culture / Enneagram reads** |
| **Universe canon** · **real-world research** · **infrastructure** · **relationship files** | ⛔ **`City_Master_Reference/` entries for other cities** |
| **This city's research log** | ⛔ **`Worked_Examples_Archive/`** |
| ⚠ **This city's own culture material — LAST, per §2** | ⛔ **The differentiation table's other columns** |

> ### The line, stated once: **ATTRIBUTES about any city are open. CONCLUSIONS about any OTHER city are not.**
> **A census figure for Zhongshan is an attribute and is open.** **Zhongshan's capability profile is a
> conclusion and is closed until Step 6.**

# 4. WHERE THE GATES SIT — one moves, sixteen do not

**`04` already resolves this and the warm mode inherits it unchanged:**

> **Gate 6 *(duplicate institutions)* is *"unrunnable in a cold pass, by construction"* — it needs the

own earlier states · the nearest analogous location at another scale · real-world comparables ·
the generator-conflict method.

# 5. DECLARATION — required, in the frame block

**`§C.5`:** ***"Declare the run WARM, explicitly. A warm run is honest. A 'semi-cold' run is a warm run
wearing a cold run's credibility."***

```
**Run mode:**        WARM  /  COLD
**Other cities:**    CLOSED until Step 6   [warm default]
**Own culture material read at:**  Step 0.4 item 6, as a CHECK   [state where it was actually read]
**If COLD:** pre-contamination review status + both pins verified
```

> ## ⛔ THERE IS NO THIRD MODE.
> **`§C.5`: *"There is no 'semi-cold.' Contamination at the SPINE is not partitionable."*** **A run is warm or
> it is cold. A cold run that takes a spine-level leak becomes WARM and is relabelled — not downgraded,
> relabelled.** ***A false-cold run is unrecoverable; a warm run is merely warm.***

### ⚠ And the differentiation set must record the mode per city
***Otherwise the set silently mixes two evidence classes***, and a later reader cannot tell which cities'
convergence results mean anything.

# 6. WHAT WARM MODE GIVES UP — and how much is recoverable

| Lost | Recoverable? |
|---|---|
| **The M-35 evidence class** — independent reproduction of a withheld finding | ❌ **No.** Requires a genuine cold run. **Already banked once; re-purchase only if fresh proof is wanted** |
| **Cold-read-as-canon-audit** — `04` Part IV's four live canon errors | ⚠ **Mostly.** A mechanical cross-source contradiction sweep *(spec vs census vs Division-of-Industry, all 37)* catches the same class without a cold pass |

> ### ⭐ Suggested pattern, not a rule
> **Build warm. Periodically cold-run ONE city as a calibration check** — chosen, per `04` Part IV, *because
> it looks least likely to conform*, not because it is convenient.
