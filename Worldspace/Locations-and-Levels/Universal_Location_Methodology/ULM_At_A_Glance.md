## THE 17 GATES *(all inside Step 7)*

| # | Gate | Checks |
|---|---|---|
| **0** | Completion claim | Does the tracker's claim match the file — fails in BOTH directions |
| **1** | Coverage | Is each phase answered, not gestured at — verify the scan finds a known hit before trusting any zero |
| **2** | General population | No narrow role or minority standing in for the whole population |
| **3** | Internal contradiction | Read Ordinary Life (Phase 4) last; check every other phase against it |
| **4** | Swap test | Would the finding survive, swapped onto the toughest comparable — report the WEAKEST finding, not just a pass |
| **5** | Cross-location consistency | Export/import coherence · shared-environment spillover accounted for · new categories cross-referenced |
| **6** | Duplicate institutions | **In-run:** same institution named twice, within this location only. Against-siblings half is TERMINAL |
| **7** | Research accounting | Every researched pick: changed a finding / ornamented one / deliberately withheld / omitted — expect ~70–80% changed |
| **8** | Standout | Name the single strongest thing the pass produced, and why |
| **9** | Asymmetry | For every threshold/gate/verdict: does it run both ways, is there a route back — runs TWICE (inherited material, then this pass's own) |
| **10** | Review Panel | `00f`, unchanged — peer-free `unmet` test: would satisfying this replace something specific with something true anywhere? |
| **11** | Plausibility | Would a person actually do this, at this cost, for this reason — population ÷ extent is the one purely mechanical check here |
| **C** | Canon check (federated) | The 3-tier search (universe repo / project / sibling projects) actually run, paths named · shared constants checked at their source |
| **F** | Frame integrity | Type, band, status, temporal frame all still match the Step 0 declaration |
| **I** | Inheritance classification | Determined / inflected / originated / aggregated correctly assigned — watch an Originated:Inflected ratio worse than ~3:1 |
| **P** | Parent reconciliation | *(Parent passes only.)* Reconciles children's provisional assumptions — confirm, contradict, or leave open, explicitly |
| **G** | Generator honesty | Were ≥3 independent generators actually run to full profiles before comparing · were nulls recorded · was research/Unrecognized-Instrument sequencing honored |
