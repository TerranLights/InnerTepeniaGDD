## Session 1 — 2026-08-31, serving Phase 1 (Constraint & Capability)

**Deficit/question being researched against:** Highway 37's own elevation profile — the map at
`Reference/Images/Maps/Antarctica_highway_map_by_topology.jpeg` shows the route running almost entirely through
the East Antarctic interior high plateau, and the pre-flight's REQUESTED items flagged founding condition and
chokepoints/seasonality as thin. Needed real figures rather than an impression from the map image alone.

**Exact search strings, verbatim:**
1. `Concordia Station Dome C Antarctica elevation altitude meters`
2. `Vostok Station Antarctica elevation altitude meters Syowa Station elevation`

**Sources actually used:**
- [Dome C — Wikipedia](https://en.wikipedia.org/wiki/Dome_C)
- [Concordia Station — Wikipedia](https://en.wikipedia.org/wiki/Concordia_Station)
- [Vostok Station — Wikipedia](https://en.wikipedia.org/wiki/Vostok_Station)
- [Showa Station (Antarctica) — Wikipedia](https://en.wikipedia.org/wiki/Showa_Station_(Antarctica))

**Fact → finding table:**

| What came back | Which finding it became |
|---|---|
| Dome C / Concordia Station: 3,233 m ASL | Cross-checked against, and confirmed by, this project's own existing `Specs/Concordia.md` (3,233 m, "deep inland, far from any coast") — corroboration, not new information, but load-bearing corroboration since it confirms the map's placement of the real Concordia Station icon corresponds to the in-fiction city's own already-established altitude, not a map-reading error. |
| Vostok Station: 3,488 m ASL | New to this pass — not previously stated as a number anywhere in Highway 37's own material; used to build the full elevation table in Phase 1 §A. |
| Syowa Station: 29 m ASL | New to this pass — establishes the corridor's coastal end is genuinely near sea level, which is what makes the "climbs once, near the start, and never comes back down" finding (Phase 1 §A/§E) a real measured claim rather than an impression. |

**What was withheld vs. omitted:** nothing withheld. Dome Fuji's 3,810 m and Kunlun/Dome Argus's 4,093 m were
**not researched fresh** — both are already-established project canon (`02_Generators_Capability_and_Symbols.md`
§2 G2 example; `Specs/Kunlun.md`) and were used as-is per the canon-check discipline (check the source, don't
re-derive what's already settled). Recorded here so a later reader knows why only two of the four Tier-1
elevation figures show a search string.

**Divergences from source:** the reference map itself labels Dome Fuji as "3,700m," ~110 m off this project's
own established 3,810 m figure. **Not chased further** — the map is a visual reference aid, not a canon source,
and the project's own Spec-level figure (3,810 m, already load-bearing elsewhere) wins per the authority
hierarchy (`00_RUNBOOK.md` §A). Flagged here rather than silently using whichever number was more convenient.

**Open threads — surfaced but not chased:**
1. **The map's placement of the real-world "Concordia Station" icon reads visually closer to the coast (near
   Casey/Dumont d'Urville) than real Dome C's actual deep-interior position (~1,100 km inland).** This pass
   resolved the substantive question (does in-fiction Concordia inherit Dome C's altitude? — yes, confirmed by
   `Specs/Concordia.md` directly) without resolving *why* the map's icon placement looks coastal. Most likely a
   label-crowding/projection artifact of the specific map image (the same pattern already flagged once before,
   per `project_sayowa_junction_correction` memory, for Sayowa's own apparent island/mainland proximity on a
   different map). **Not pursued further because the canon-level question was independently confirmed via
   `Specs/Concordia.md`** — a future pass correcting the map image itself, if anyone does one, is a separate,
   lower-priority task.
2. **Mountain Pass Airport's own exact elevation** was not searched for, because it has no named real-world
   analog (it is an invented waypoint, not based on a specific real Antarctic site) — its position was only
   bounded (between Kunlun's 4,093 m and Vostok's 3,488 m) rather than pinned to a figure. If a future pass
   needs an exact number, the honest answer is that one does not exist and would have to be authored, not
   researched.
3. **Real-world Antarctic overland traverse routes** (the actual South Pole Traverse / McMurdo–South Pole
   highway, a genuine ice-road precedent) were not yet researched — flagged as the next research target in
   Phase 1 §G, for Phase 3 (Surface & Texture) and Phase 8 (Making), not chased in this session.
4. **Real-world seasonal-closure precedent for high-altitude Antarctic traverse routes** (does the actual South
   Pole Traverse close seasonally? what determines it?) — directly relevant to the REQUESTED chokepoints/
   seasonality item from the pre-flight, not yet researched.

## Session 2 — 2026-08-31, serving Phase 3 (Surface & Texture)

**Deficit/question being researched against:** open thread 3 from Session 1 — a real-world overland traverse
route across the East Antarctic interior, to serve as G7's comparable for this Corridor's own physical texture
and seasonal-usability questions (also directly relevant to the still-open pre-flight REQUESTED item on
chokepoints/seasonal closure).

**Exact search string, verbatim:**
`South Pole Traverse McMurdo ice road route markers flagged groomed snow crevasse detection tractor`

**Sources actually used:**
- [South Pole Traverse — Wikipedia](https://en.wikipedia.org/wiki/South_Pole_Traverse)
- [The McMurdo–South Pole Highway: The World's Most Southerly Road — WorldAtlas](https://www.worldatlas.com/articles/the-mcmurdo-south-pole-highway-the-world-s-most-southerly-road.html)

**Fact → finding table:**

| What came back | Which finding it became |
|---|---|
| The real route is flagged, not paved — built by leveling snow and filling crevasses | Phase 3 §B's core finding: Hwy 37's own "highway" terminology is functional, not a construction claim; the ice sheet's own movement forces a re-graded/marked route regardless of Tepenia's more advanced maintenance capacity |
| Travel is by tractor-and-sledge convoy with onboard living quarters, ~40 days one-way for the full real route | Phase 3 §B's convoy-vehicle framing (divergence stated: Tepenian engineering plausibly exceeds this in reliability, not assumed identical); fed Phase 4 §A's transit-day material |
| Ground-penetrating radar surveys detect crevasses pre-season; post-traverse re-grooming maintains the route | Phase 3 §E's seasonal-restriction finding — directly resolves the pre-flight's chokepoint/seasonality REQUESTED item, directionally (season-limited operation) though not to a precise date |

**What was withheld vs. omitted:** nothing withheld. **Divergence from source, stated explicitly in Phase 3 §B**
per the source-not-specification rule: this pass does not assume Hwy 37 is as primitive as the real SPoT, only
that it shares the SPoT's one non-negotiable physical constraint (a maintained, re-surveyed route rather than a
permanent paved road).

**Open threads — surfaced but not chased:**
1. **The real SPoT's exact seasonal operating window** (which specific months it runs) was not pulled from the
   search results in enough detail to state a precise figure, and this pass deliberately did not assert one to
   false precision (Phase 3 §E) — a future pass wanting an exact closure date for Hwy 37 should chase this
   specifically, cross-referenced against this corridor's own latitude-adjusted polar night length (also not
   computed here).
2. **Real-world ice-road engineering more broadly** (Canadian winter ice roads, for instance) was not researched
   as a second comparable — the SPoT was judged sufficiently close a match (Antarctic interior, plateau
   traverse, comparable purpose) that a second comparable was not pursued, per the "prioritize by difference,
   not tier, but don't skip look-far-enough" discipline; flagged in case a future pass wants a second data
   point for contrast.
