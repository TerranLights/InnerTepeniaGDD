## ⭐ Novelty: three findings the withheld material does not contain

1. **THE ARRIVAL-WAVE MISMATCH — Run 7's own standout, and it is genuinely absent from the withheld file.**
   Run 7 (Phase 2) read the census annotations closely and found that **the nations carrying "founding wave"
   flags are not the nations with modern demographic weight**: New Zealand is flagged *earliest founding wave*

   from them** — that the city's identity "was never going to come from its population's origins." **It never
   observes the mismatch itself, and never derives a tension from it.** This finding is new.
2. **The boardwalk-corridor infrastructure** (Phase 3 §C) — movement routed through fixed, marked,
   rookery-avoiding corridors as basic civic infrastructure, fused from researched real-world precedent
   (Boulders Beach). **Nothing equivalent exists in the withheld file**, which treats the rookery as sensory
   presence and seasonal rhythm but never asks how a city physically moves around 250,000 breeding pairs.
3. **Guano as the non-thematic export** (Phase 7a). The withheld §15 gives marine/resource extraction 25% but
   never names this. Compatible, and new.

# Contradictions, and the both-are-true test

**One genuine divergence, and it resolves rather than kills.**

**Withheld §19:** counterculture is ***minimal*** — *"a gateway city built around a shared, non-national civic
identity doesn't generate much of the kind of counterculture that pushes against a dominant cultural template,
because there was never a singular dominant template to push against."*

**Run 7 Phase 7d:** derived a counterculture — people maintaining deliberately single-heritage households
rather than participating in the city's constant cross-cultural negotiation.

**Both-are-true test (`02` §5.3), run before recording any kill:** **they are about different objects.** The
withheld file is describing *rebellion against a dominant template* and correctly says there isn't one to rebel
against. Run 7 described *opting out of a process* — and its own text already says these are "people for whom
the negotiation itself is exhausting or unwanted, not people opposed to anyone else's presence." **That is not
a counterculture in the withheld file's sense.**

**Resolution: the withheld file's calibration is better, and Run 7's content survives with a corrected label.**
It is a private preference pattern, not a counterculture. **Not a kill — a mislabeling.**

# What the cold pass MISSED — recorded honestly

**Two real gaps, both in the same register:**

1. **Heritage preservation as the city's defining work.** Withheld §15 gives *technical/scientific 20% —
   heritage site preservation* and *education 15% — historical/civic memory-keeping*; §17 makes **archival
   record-keeping the robot population's respected specialization**; §24 and §25 build on it further.
   **Run 7 found none of this.** It derived a maritime-logistics economy (correct, and present in the withheld
   file at 25%+25%) but entirely missed that **a third of the city's stated economy is memory-keeping.**
2. **The fragility question.** Withheld §5b: *"what happens to that identity if the hut itself is lost?"* — a
   fault line the withheld file says "was alive in Cape Adare's culture long before the Long Night War made it
   literal." **Run 7's Phase 6 §D reached for a failure state and chose *precedence being contested*.**
   Close, but it missed the sharper, more specific version sitting in the material: **not "who was first?" but
   "what if the proof burns?"**

**Why both were missed is diagnosable, not mysterious:** the admissible Specs file names the hut as a landmark
and a heritage site, but **nothing admissible states that heritage work is a major economic sector.** That fact
lived only in the withheld file. **This is input scarcity, not analytical failure** — and it is the clearest
single illustration of M-54's own point that this run has produced.
