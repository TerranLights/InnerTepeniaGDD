# Run 7 — Cape Adare, Cold

**Run started 2026-08-31.** Chosen per the developer's direct instruction: an under-developed city with zero
highway connection to Highway 37. Cape Adare has the highest TBD-density of any of the 35 outer cities (11 in
its own Specs file) and is structurally a minor connector-stop off Hwy 183, not a main-line city — two
independent thinness signals, neither of which Shirayuki (the other standing "never run" candidate) shares to
the same degree.

---

## ⚠ 0. THE FRAME, STATED FIRST, BEFORE ANYTHING ELSE — this location is written LIVING, not as ruins

**Per `01_Frame_Typology_and_Inheritance.md` §4.1 (added during Highway 37 Run 6, binding on every run since):
absent a specific reason otherwise, a pass defaults to the Second Interwar Period baseline — before the Long
Night War — not to the post-war present.**

**Cape Adare's canon marks it `Destroyed` — but that status is itself a Long Night War consequence** (confirmed
directly: `Specs/Cape_Adare.md` — *"Destroyed — historical site"*; the destruction is explicitly a war event,
not a pre-war or inherent condition). **Per §4.1, that fact is OUT OF SCOPE for this pass entirely.** This run
writes Cape Adare exactly as it stood before the war: a living, populated, functioning city of **1,050,051**
people (Census II, the pre-destruction figure — used here as the pass's own population baseline, not as a
"before it was destroyed" framing device, but simply as what the city's population *is*, in this pass's own
frame). **No ruin, no aftermath, no penguin-rookery-reclaiming-the-wreckage imagery, no elegiac register. This
is not a memorial pass. It is a pass about a real, living place, on its own terms, in the period before
anything happened to it.**

**This is not a new interpretation invented for this run** — it is the same convention `01` §4 already states
as standing practice for every one of the 35 outer cities *("the outer cities are written pre-war")*, now made
explicit and unambiguous rather than assumed. **Every phase below is written in the present tense, about a
living city, throughout.**

## ⚠ 6. SELF-CORRECTION, caught mid-pass — `Specs/Cape_Adare.md` is MIXED, not fully admissible

**What I believed:** that `Specs/Cape_Adare.md`, having been checked at its first ~20 lines and matching the
"Specs = pure physical/founding/census facts" pattern every prior run's Specs files have followed, was
admissible in full.

**Why it was wrong:** reading the complete file (required for Phase 1 research, not skipped) surfaced a
**"Character & Culture" section (lines 111–121)** containing genuine culture-pass conclusions — civic
temperament ("had the character of a city that knew it was first"), a named developer-vision paragraph
("strongly community-driven," "life moves slowly and deliberately," specific instrumentation: "guitars,
violins, cellos, tagelharpas"), and an explicit self-citation to `Local_Cultures/Janbogo_Subnet/Cape_Adare.md`
for "full detail." **This is not an attribute. It is a conclusion, sitting inside a file this pass had already
cleared.**

**What changed:** per `05` §6.1a rule 1 (*"a file is admissible only if every section of it is... there is no
partial read"*), `Specs/Cape_Adare.md` is corrected to **MIXED**, not ADMISSIBLE. **The admissible portions**
(Population & Composition, Geographic Basis's factual content, Founding's factual content, Notable Locations'
bare listing, Current Status) remain usable. **The "Character & Culture" section (lines 111–121) specifically
is INADMISSIBLE** and is excluded from every subsequent phase in this pass.

**Provenance discipline, per the Worked-Example-Provenance protocol's third obligation (unavoidable absorption):**
having now read this section, **any finding in this pass that resembles it — community-drivenness, a slow/
deliberate pace, acoustic/folk instrumentation — must be tagged `[SELF-ORIGINATED]` and treated as
corroboration only, never presented as this pass's own independent derivation.** This constrains Phase 4
(Ordinary Life) and Phase 8 (Making) specifically, where this kind of material would otherwise be derived fresh.

**Logged to the shared observations file as M-51** — a fourth confirmed instance of the mixed-file pattern,
and the first one caught inside a file-type (`Specs/`) previously treated as categorically safe across every
prior run of this methodology.

**A second instance, same file, caught during Phase 10 prep**: the Specs file's own **"Notable Figures"**
section names two role-placeholders explicitly citing *"proposed `Cape_Adare_Full_Extrapolation.md` Section
VII"* as their origin — downstream of the same withheld file, same pattern as the Character & Culture section.
**Excluded from this pass's admissible list as well.** In practice this changes little, since Phase 10's own
binding rule already forbids inventing or using proper names for role-archetype figures — but the
