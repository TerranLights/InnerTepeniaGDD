# Zhongshan-Specific Content, Extracted From the Universal Methodology Files

**Created 2026-08-31, at the developer's direction.** The universal methodology (`00_RUNBOOK.md`, `01`–`05`,
`00f_Review_Panel.md`, `Cultural_Synthesis_Techniques.md`, `Real-World_Basis_Extrapolation_Method.md`) must
stay usable for **any** location, not accumulate content specific to one city. This file holds material that
was previously written inline in those files, specifically and exclusively about Zhongshan, moved out so it
remains available for Zhongshan's own future work without living permanently inside the general-purpose
instrument.

**Companion to `06_Worked_Example_Provenance.md`**, which tracks *which sections* carry which location's
worked examples so a cold re-run can skip them — that manifest's structure and purpose are unchanged by this
file. This file holds the actual extracted content; `06` still says where it used to live and why it matters.

**Each entry below names the source file/section it was removed from**, and what replaced it there (usually
nothing, or a shortened generic-language pointer).
