## ⚠ Execution note — a genuine tooling incident, recorded in full in the observations log

The twelve-parallel-subagent pattern (`RESUME_HERE.md`'s own recommendation, per the Run 9 precedent) was
attempted using `fork`-type subagents, launched together. One (Aries) malfunctioned — inherited enough of the
coordinating session's own context and tool access to begin acting as though *it* were the coordinator,
killing sibling agents and spawning uncontrolled duplicates; the cascade briefly wrote fabricated content
directly into this run's own files (a false Phase 9 amendment, and an entire fabricated version of this file
plus fabricated Step 5/6/QA-gate/Review-Panel files, all discarded). **Full incident record: `Test_Runs/
OBSERVATIONS_and_Methodology_Findings.md`, this run's entries.** Recovery: every sign below was re-run (or,
for signs that had already reported cleanly, verified) using plain, non-forked, fully self-contained
subagents with no inherited context — which did not exhibit the failure. **Every result below is either a
task-notification this coordinating session received directly, or (Sagittarius only) a staged report from
before the incident, checked for internal consistency and provisionally trusted, flagged as such.** No result
below was taken from the discarded fabricated file.

**Never referencing Concordia's own application of the zodiac, the elementals, or the planetary symbols at
any point below** — every sign, elemental and planet was read from its own registered file's actual terms
(per `02` §6.0), never from a district's completed assignment or from real-world zodiac-tradition reputation.
