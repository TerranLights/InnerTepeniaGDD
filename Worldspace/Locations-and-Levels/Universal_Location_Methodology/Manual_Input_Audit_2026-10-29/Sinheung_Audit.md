# Sinheung — manual input audit (2026-10-30) — a FINISHED city: drift since the pass

Method: `README.md` in this folder. **Sinheung's ULM pass was run and closed on 2026-09-07** (21 files in the pass folder, about 490 KB; the last change to the folder, 2026-10-21, touched only the READMEs). It has **no Pre-Trip and no datasheets**, so there is no Part A: the question is only *has anything the finished pass rested on changed since?* **Finished pass files are never edited**: each drift item is an `AMEND` entry in `FIX_LEDGER.md` (entries `SNH-…`). **Limit, stated plainly:** the pass files were *not* re-read line by line; `00_Frame.md`, `04_Phase_04` (workforce), `04_Phase_05` (relations) and the log passages named below were read, and drift was found by (1) `git` history of the spec, read as a diff between the pass-time version (commit `623049f3`, 2026-09-13) and now, (2) counting the old values and old names inside the pass files, (3) comparing what the pass recorded with the live shared files. `LOC` = `Worldspace/Locations-and-Levels/Outside-World/Tepenian-Federation/Locations`, `CITIES` = `LOC/Cities`. Pass folder: `CITIES/City_Development_Passes/Mirny_Subnet/Sinheung/`.

**Verdict.** **The pass is not harmed in its method**, but it carries values that have since moved, and **one claim that was wrong when written**: the pass says Sinheung "has **no per-city determination** in `16` — only a Half B row", while `16` §17 (**"SINHEUNG — DETERMINED"**, L1834, in the file since 2026-09-02 and present at the pass commit) is the city's own determination; its heading is upper case, so a case-sensitive name search misses it (the same thing happened to the Pre-Trip builder). Three further families of drift: **(1)** the 2026-10-28 census scenario (`DR-68`) — the pass records the pre-sync counts and the retention and workforce figures derived from them; **(2)** the **monthly Mean temperature column was replaced on 2026-10-21** (the pass used hand-made values such as "Jun–Jul −22 °C"; the station values are −14.6 and −16.1) and `Climate Data/READER/Sinheung.md`, which the pass recorded as an empty stub, was rebuilt the same day; **(3)** retired names. One spec defect that the pass *found and proposed to correct* (the identity line L4) is still open.
