# Zhongshan — manual input audit (2026-10-30) — TWO pass folders: Opus (finished) and Sonnet (partial trial)

Method: `README.md` in this folder. Zhongshan has two pass folders under `CITIES/City_Development_Passes/Mirny_Subnet/`: **`Zhongshan_Opus/`** (a complete ULM pass, Steps −1 to 10, written 2026-09-08 to 2026-09-11, committed 2026-09-13; 25 files, about 700 KB) and **`Zhongshan_Sonnet/`** (a partial trial, Step −1 to Phase 3: 9 files, about 220 KB). Each has an older hand-written **Pre-Trip** (generated 2026-09-07 per the recipe; runbook line numbers refreshed 2026-10-21; kept as a record) and **no datasheets**. So each folder gets (A) the Pre-Trip checked the usual way and (B) a drift check of the pass. **The two Pre-Trips are identical except one verification line** (528), so Part A is written once. **Finished pass files are never edited**: each drift item is an `AMEND` entry in `FIX_LEDGER.md` (Opus: `ZSO-…`; Sonnet: `ZSS-…`). **Limit, stated plainly:** the pass files were *not* re-read line by line; drift was found by (1) `git` history of the spec, read as a diff between the pass-time version (commit `623049f3`, 2026-09-13) and now, (2) counting the old values and names inside both folders, (3) comparing what the passes recorded with the live shared files. `LOC` = `Worldspace/Locations-and-Levels/Outside-World/Tepenian-Federation/Locations`, `CITIES` = `LOC/Cities`.

**Verdict.** **Nothing blocks.** The Pre-Trip's 110 absolute addresses all resolve except one (`Zhongshan_Opus/09.6_Input_Audit.md`, a pass output the Opus pass never wrote; in the Sonnet folder five pass outputs are absent, as a partial trial must be), and the runbook ranges it cites still land (except the end of Step 10: the runbook has grown from 3,172 to 3,179 lines). What has moved since the passes: **(1)** the 2026-10-28 census scenario (`DR-68`) — both passes record the pre-sync counts and the retention, workforce and footprint figures derived from them; **(2)** the Pre-Trip's own pre-sync figures (§E census, §J oasis footprint — the latter was already on pre-cut numbers when written); **(3)** retired names; **(4)** the `Section 15` determination for the city (`16` §18, L1917) is **correctly used by the Opus pass** (an upper-case heading the search would miss), but its counts are on the pre-cut workforce; **(5)** three spec sentences the passes could lean on were rewritten (the name's honorific, the "founding operator" wording, the Settled paragraph's basis).
