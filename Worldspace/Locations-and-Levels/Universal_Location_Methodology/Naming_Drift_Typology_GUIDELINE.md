# NAMING DRIFT — a typology of how Tepenian place names change

> # ⚠ THIS IS A POSSIBLE GUIDELINE. **IT IS NOT A RULE.**
> **Developer framing, 2026-09-04:** ***"more of a 'possible guideline'."***
>
> **Nothing here is binding.** **No pass is required to apply it, no gate checks it, and a location whose
> names have not drifted at all is a legitimate and unremarkable outcome.** ***Read it the way
> `Cultural_Synthesis_Techniques.md` asks its own entries to be read: a question with a structure, never a
> result to reproduce.***

> ## ⛔ AND IT NEVER SUPPLIES A NAME.
> **`05` §3: *a location's official in-fiction name is RESERVED to the developer. A pass may use a working
> designation and must not settle one.*** ***This guideline can identify that a place is a candidate for
> drift, and suggest WHICH KIND. It cannot name anything.*** **Output is a `REQUESTED` item, never a
> `PRODUCED` one.**

**Layer: PROJECT.** Derived from seven existing instances in this corpus. **Status: descriptive, unvalidated
— it was extracted from what already happened, not designed in advance.**

# 0. The observation that produced it

**Developer, 2026-09-04:** ***"As robots continue to live in Antarctica and build the civilization of
Tepenia, after enough time has passed, they've built their cities, and they've developed their country, they
would change the names of things."***

**Measured against the corpus, 2026-09-04:**

| | |
|---|---|
| **City names that have drifted** | **at least 7** — and 5 carry an explicit `**Tepenian city name:**` field |
| **Landscape features that have drifted** | ⛔ **0** |

> ### ***The cities Tepenified. The landscape did not — YET.***
> **Every harbor, bay, cape, mountain range and island inside those cities still carries its 21st-century
> survey name** — Horseshoe Harbor, Holme Bay, Mac.Robertson Land, the Prince Charles Mountains, Prydz Bay,
> the Larsemann Hills, East Ongul Island, the Vestfold Hills, the Schirmacher Oasis.

## ⏸️ AND THE LANDSCAPE HALF IS AN OPEN QUESTION, NOT A SETTLED ABSENCE

**Developer, 2026-09-04:** ***"In general likeliness, there is a reasonable possibility that names of natural
settings, landmarks, and sites will probably get renamed as well. I just currently have no idea how, or to
what."***

> ### ⛔ SO THE 0-OF-N ABOVE IS A GAP, NOT A DESIGN DECISION.
> ***Do not read the survey names as deliberate, and do not read them as settled.*** **They are the state of
> a question nobody has worked yet.**

**What that means for a pass that meets one:**

| | |
|---|---|
| ✅ **Legitimate** | **name the feature by its current survey name, and flag it as PROVISIONAL** — the same treatment any open in-fiction name gets |
| ✅ **Legitimate** | **note WHICH of the seven pressures below would plausibly apply**, as a `REQUESTED` item |
| ⛔ **Not legitimate** | **inventing the Tepenian name.** *`05` §3 — RESERVED, and the developer has said explicitly that the "to what" is undecided* |
| ⛔ **Not legitimate** | **treating a survey name as characterizing** — *e.g. "the city still calls it Holme Bay, which shows deference to its founders."* ***That reads a finding out of an unfinished question*** |

**Why that last row matters more than it looks:** *a pass looking for meaning will find some in an unrenamed
landscape, and the meaning will be spurious* — **the names are unrenamed because the work has not been done,
not because anyone in-world chose to keep them.**

> **Why any of this might matter, offered as an observation rather than a claim:** *a city whose surrounding
> landscape still carries the names of a survey conducted by people who no longer exist reads as **occupied**.
> A city whose landscape carries its own names reads as **inhabited**.* **260 years is a long time to keep
> using somebody else's map labels.**

# 1. THE SEVEN TYPES — each derived from a real instance, none invented

| # | Type | Mechanism | The instance it came from |
|--:|---|---|---|
| **1** | **Phonetic truncation under demographic turnover** | A long name shortens as the community that pronounced it fully is outnumbered by later arrivals | ⭐ **Lazar** ← *Novolazarevskaya* — the spec states it plainly: *"shortened as the founding Russian demographic was overtaken by later American, German, French, and Brazilian immigration"* |
| **2** | **Acronym lexicalization** | An institutional acronym stops being read as letters and becomes a word | **Sanay** ← *SANAE* (South African National Antarctic Expedition) |
| **3** | **Transliteration settling** | A name in another script settles into one stable local spelling, losing its diacritics and its original orthography | **Sayowa** ← *Syowa / Shōwa / 昭和* |
| **4** | **Fusion** | Two adjacent settlements coalesce and their names merge into one | **Abowasa** ← *Aboa* (Finland) + *Wasa* (Sweden) |
| **5** | **Orthographic simplification** | A foreign digraph or cluster is respelled the way locals actually write it | **Zukelli** ← *Zucchelli* (`cch` → `k`) |
| **6** | **Title accretion** | A functional prefix attaches and becomes part of the name | **Fort McMurdo** ← *McMurdo* |
| **7** | **Replacement** ⚠ *not drift* | The old name is set aside and a new one is chosen outright | **Shirayuki** ← the *Bharati* site. **A deliberate act, not erosion — and note it produced a name in the founding population's own language** |

> ### ⚠ Type 7 is different in kind and should not be blended with 1–6.
> **Types 1–6 are things that HAPPEN TO a name over time. Type 7 is a DECISION.** ***A pass can plausibly
> observe erosion. It cannot decide a replacement*** — that is squarely `05` §3.

# 2. THE QUESTION, if a pass wants to run it

> **For a given place: *has anyone here had 260 years and a reason to stop calling it what the survey called
> it?* And if so, WHICH of the seven pressures applies?**

**Three sub-questions that make it concrete:**

1. **Who says the name most often, and can they pronounce it comfortably?** *(Type 1 and 5 both come from
   friction between a name and the mouths using it.)*
2. **Does the name still mean anything to anyone here?** An acronym nobody can expand, a person nobody
   remembers, a nation that no longer holds the claim — **all three are unstable in different ways.**
3. **Is the feature used daily, or only referenced?** ***A harbor people work in every day is under far more
   naming pressure than a mountain range on the horizon.*** **Daily use erodes; distant reference preserves.**

## A divergence table — the same pressure producing unlike outcomes

| If the place is… | The likely pressure | And the plausible shape |
|---|---|---|
| A working harbor, used daily by the same crews | **1 / 5** — wear | shortening, respelling, a nickname hardening into the name |
| Named for an institution nobody belongs to any more | **2** — lexicalization | the acronym becomes a word and loses its expansion |
| Named in a script the local population does not use | **3** — settling | one spelling wins; the diacritics go |
| Two settlements that grew together | **4** — fusion | one name from two |
| Named for a person still actively venerated | ⛔ **probably none** | **veneration preserves.** *St. Douglas at Mawson is a live cult of memory; that name is under no pressure at all* |
| A feature nobody visits | ⛔ **probably none** | distant reference preserves |

> ### ⭐ The last two rows are the useful ones, and they are why this is a guideline rather than a rule.
> ***Not everything drifts, and a place where nothing drifted is telling you something*** — that the name is
> load-bearing, venerated, or simply never spoken aloud.

# 3. ⚠ WHAT THIS MUST NOT BECOME

| ⛔ Do not | Why |
|---|---|
| **Supply a name** | `05` §3 — RESERVED. **Emit a `REQUESTED` item instead** |
| **Rename anything in canon** | drift is a developer decision; this instrument only spots candidates |
| **Make the ORIGINAL name causal** | `Disciplines/Real-World_Basis_Extrapolation_Method.md`'s standing principle: ***a real-world basis is a COORDINATE, never a CAUSE.*** **The original name fixes what a thing is called; it must never explain anything about the people** |
| **Read national origin into a naming outcome** | ⛔ **`No_National_Stereotypes.md` — GPS facts only.** *Type 1's demographic mechanism is about numbers of speakers, not about national character, and must stay that way* |
| **Force a result** | **A null is a legitimate outcome and needs no apology.** *(`03` §0.2 item 4 — a null is a result; record it and say why)* |
| **Apply it retroactively to settled names** | **The seven instances above are canon and closed.** This describes them; it does not reopen them |

# 5. HONEST LIMITS

- **Derived from seven instances, all city names.** ***It has never been applied to a landscape feature, which
  is the case it was written for.*** **Treat its first use as a test of the guideline as much as of the place.**
- **The seven types are what this corpus happens to contain.** **An eighth almost certainly exists.**
- **No gate checks any of this, and none should.** **It is a prompt.**
- ⚠ **A guideline that produces a satisfying name is more persuasive than one that produces a null** — and
  that asymmetry pushes toward inventing drift where none is warranted. ***The rows in §2's table that
  predict NO drift are there to counterweight exactly that pull.***
