# Independent Lattice — Guidelines

**Status: broad-scope and per-district guidelines only, established 2026-07-21. Not a design document —
no actual quest structure, breadcrumb placement, discovery triggers, or resolution content exists yet.**
This is a "what must be true / what cannot be true" reference, the same calibration level already used to
establish The Flood's cause and mechanism (`District_Canon_Reference.md`, Pisces section) — enough
foundation to build actual content on later without contradicting anything already established, while the
world is still being built out further.

**Working name "Independent Lattice" is Grok-suggested and developer-approved.** See `TODO.md`'s own entry
for the base premise: a secret alternative endgame solution with zero mechanical scaffolding (no stat
checks, no skill checks, no perks, no quest markers, no notifications) — the player can build a
decentralized/distributed power grid as a complete alternative to the failing central grid beneath the Hub,
discoverable only through scattered environmental storytelling (notes, terminal entries, audio logs, NPC
dialogue fragments) with no single source explaining the whole picture.

**Primary source constraint for everything below:** `Worldspace/Energy_Grid_Failure_Rationale.md`'s 16
established reasons "just fixing the grid" isn't viable. Every guideline here is built to be consistent with
all 16, not to contradict or route around them narratively — the Lattice has to be a genuine alternative
that works *within* those constraints, not a magic exception to them.

---

## Which districts this needs to occupy

**All 13 — confirmed, not padded.** Every district below has a distinct, non-redundant, lore-grounded reason
to be involved, found by cross-referencing `District_Canon_Reference.md`'s own already-established facts
against the Lattice's own structural needs (technical origin, physical construction, material sourcing,
concealment, breadcrumb distribution, political opposition, and political sympathy). This maximizes player
involvement across the whole city, which the developer confirmed is the preferred outcome if a genuine
(non-forced) case exists for all 13 — it does.

| District | Role in the Lattice |
|---|---|
| Virgo | Physically builds and routes it — knows every tunnel, has unmapped "Deep Level" space to hide it in |
| Aquarius | The technical/conceptual origin point — the already-canon "Living Network Experiment" |
| Capricorn | Fabricates the physical hardware, likely via the same underground channels as their existing suppressed labor movement |
| Pisces | Moves black-market/salvaged components — they already smuggle "generators and power cells" |
| Cancer | Hosts the earliest, most sympathetic seed nodes — protecting incubators/medical gear, not ideology |
| Taurus | The cultural template — household-level self-sufficiency already exists here, just unpoliticized |
| Leo | Motivated by The Dimming's trauma to want independence from Aries, but hasn't achieved it |
| Scorpio | Provides concealment — their existing underground/hidden-space culture |
| Gemini | Where rumors/fragments circulate as unverified Truth-Market data |
| Libra | Holds the buried bureaucratic paper trail of it having been proposed and shelved before |
| Sagittarius | Frontier outposts already run semi-independently out of necessity, not politics |
| Aries | The natural opponent — a working alternative threatens their entire source of political leverage |
| The Hub | Not a builder — the exposed, watched center of the *old* system the Lattice is an alternative to |

## Broad-scope guidelines (full-city level)

### A. Must be true

1. **It can never require repairing, removing, or overriding the Triage Protocol safeguards** *(renamed
   2026-07-23 from "Ghost Protocol")* embedded in the Power Core. That's an established "scorched earth"
   shutdown trigger (`Energy_Grid_Failure_Rationale.md` #9). The Lattice has to be a parallel system that
   exists *alongside* the old core, never a fix applied to
   it.
2. **It cannot trigger Amundsen Resonance Effect feedback loops** (#11). This means every node has to stay
   genuinely small-scale and local — no single large synchronized intervention on the existing grid
   architecture, which is what triggers the resonance risk in the first place.
3. **It cannot require unanimous city-wide political agreement.** That's already established as impossible
   for decades (#4). The Lattice's entire premise has to be that it *avoids* needing consensus — it succeeds
   precisely because it doesn't wait for permission.
4. **It has to route around, not through, the existing Interdependent Infrastructure Debt** (#13 — power,
   Arcanet, siligel, and water systems are all physically tangled together, and touching one damages
   another). This means it needs genuinely separate physical space to occupy — which is exactly what Virgo's
   uncharted Deep Level chambers provide, and is the mechanical reason Virgo has to be the primary builder.
5. **It needs a real technical origin already sitting in established lore**, not an invention from nothing.
   Aquarius's "Living Network Experiment" (`District_Canon_Reference.md`, Aquarius section — ongoing ~30
   years, semi-secret, may be approaching collapse) fills this role and should not be duplicated or
   contradicted by inventing a second, separate origin elsewhere.
6. **It needs genuine opposition from parties who profit from the current instability.**
   `Energy_Grid_Failure_Rationale.md` #15 already names Pisces smugglers, certain Capricorn industrialists
   (repair contracts), and certain Libra elements (rationing-authority control) as beneficiaries of the
   status quo. Any Lattice content has to be consistent with these specific parties having a real motive to
   not want it to succeed — not opposition invented fresh.
7. **Material scarcity still fully applies.** The established rare-alloy/quantum-regulator shortage (#3)
   isn't waved away for this — sourcing has to run through salvage, black-market channels (Pisces), or
   expedition-recovered material, the same constraints as everything else in this world.
8. **Discovery has to stay genuinely fragmented across the whole game**, per the existing unmarked-questline
   design rule — no single location, character, or document can ever explain the full picture on its own.

### B. Cannot be true

1. **No single mastermind or cabal suppressing it.** Any resistance has to be structural and self-interested
   (specific factions protecting specific specific interests), consistent with this project's binding
   non-malice worldbuilding rule — never a villain orchestrating suppression.
2. **It cannot be a clean, total fix to the whole city's power grid in one triumphant act.** That would
   undercut the entire "Great Blackout" climax and the game's own established thesis (the whole reason
   `Energy_Grid_Failure_Rationale.md` exists) that there is no easy fix. The Lattice is a real, viable,
   *partial* alternative — it changes the shape of the problem, it doesn't solve it outright.
3. **No single district can own or receive sole credit for it.** If one district could plausibly claim full
   authorship, the "requires maximum player involvement across the whole city" premise collapses into
   something much smaller and less interesting.
4. **It cannot be common knowledge or an open secret** the way Pisces' Tolerance Pact already is. It has to
   stay genuinely obscure and fragmented — closer to the Independent Lattice's own stated design (zero
   mechanical scaffolding, pure attention-based discovery) than to any existing "everybody sort of knows"
   arrangement.

## Per-district guidelines

### Cancer
- **Must be true:** Cancer's own established chronic power-allocation disputes with Aries (repeatedly
  endangering incubators, medical equipment, and heating in care facilities) make a quiet, small-scale
  backup-generation presence here completely plausible and in-character — framed entirely as an extension of
  caregiving, never as a political statement.
- **Cannot be true:** Cancer cannot have originated the underlying technology themselves — engineering
  invention isn't their established competency. Cancer also cannot be shown taking a political stance on the
  Lattice either way (for or against) — that would contradict their established total avoidance of the
  political register in favor of pure care-focused identity.

### Taurus
- **Must be true:** Household-level self-sufficiency and hyper-efficient private thermal/insulation
  management already exist here as established culture (`District_Canon_Reference.md` notes Taurus
  residents "often know more about insulation engineering than Capricorn's industrial teams — they just
  apply it at household scale"). Any early Lattice-adjacent material found in Taurus should read as an
  extension of existing tradition and self-reliance, not a new idea.
- **Cannot be true:** It cannot read as rebellion, defiance, or destabilizing change — that directly
  contradicts Taurus's defining "stubborn resistance to destabilizing change" and conservative culture.
  Whatever's found here has to be framed internally as continuity, not innovation.

### Leo
- **Must be true:** Any Lattice-related thread in Leo should trace back specifically to The Dimming (the
  six-month Aries power cutoff that is Leo's single most sacred, defining trauma) — it's the one piece of
  Leo's own history that would organically motivate wanting independence from centralized power control.
- **Cannot be true:** Leo cannot already have a working independent power solution. If they did, their
  present-day culture of aggressively lobbying and strong-arming Aries for priority energy allocation
  wouldn't make sense — they'd already be free of that dependency.

### Scorpio
- **Must be true:** Scorpio's already-established "Underground Evolution" (radical/unregulated work pushed
  into hidden spaces due to Taurus and Libra's wariness) is a ready-made structural home for Lattice
  infrastructure to exist inside or adjacent to, discoverable through Scorpio's own existing
  descent/integration/emergence mask-culture threads.
- **Cannot be true:** The Lattice cannot become a core Scorpio institution or purpose in its own right — any
  presence here has to read as using Scorpio's existing concealment infrastructure, not as something
  Scorpio itself is dedicated to building.

### Aries
- **Must be true:** Aries has to be the Lattice's natural, in-character opponent. A working decentralized
  alternative directly threatens the entire basis of Aries's outsized political power (their established
  "Political Weapon" — the implicit threat of controlled blackouts only works because they're the sole
  lifeline). Discovery by Aries personnel should read as an existential threat to their own relevance and
  leverage, not simple institutional caution.
- **Cannot be true:** Aries cannot officially, institutionally support the Lattice. Any individual
  sympathizer (e.g., an engineer who has seen enough Overclock-Martyr-style deaths to want a safer
  alternative) has to be a personal, rogue exception explicitly not representing district policy.

### Capricorn
- **Must be true:** Capricorn has to be where the physical hardware gets fabricated, most plausibly routed
  through the same underground channels already established for Capricorn's own suppressed robot-rights
  movement — reusing existing lore infrastructure of secrecy rather than inventing a second, unrelated
  underground network.
- **Cannot be true:** Capricorn's official leadership and merit-board establishment cannot be shown
  supporting the Lattice — `Energy_Grid_Failure_Rationale.md` #15 already establishes that Capricorn
  industrialists directly benefit from emergency repair contracts tied to the current crisis. Any support
  has to come from the underground/dissident layer only.

### Aquarius
- **Must be true:** Aquarius has to be the Lattice's technical/conceptual origin point, via the already-canon
  "Living Network Experiment." This should be treated as the real, traceable root of the underlying
  distributed-network concept, not one option among several.
- **Cannot be true:** Aquarius cannot have already deliberately built a complete, working, city-scale version
  of this on purpose. Their established pattern is well-intentioned ideas producing unintended consequences
  (Contamination Events, the Failed Utopias) — a full clean success here would contradict that pattern and
  would also mean Aquarius should have already deployed it themselves.

### Libra
- **Must be true:** Somewhere in Libra's own classified archive (Treaty Archive Vaults or equivalent) there
  has to be a genuine, buried bureaucratic paper trail showing a distributed-grid alternative was proposed
  and studied at some point in the past, then quietly shelved — consistent with Libra's own slow, procedural,
  precedent-obsessed culture.
- **Cannot be true:** Libra cannot respond to discovering the Lattice with swift, decisive, centralized
  action. That directly contradicts their established "congenitally incapable of responding to anything in
  under six weeks" culture. Any Libra-sourced resistance has to be slow, bureaucratic, and plausibly
  deniable — never an urgent crackdown.

### Gemini
- **Must be true:** Fragments and rumors of the Lattice should circulate through Gemini's existing Twin
  Channels and Truth Markets exactly the way all information already does there — as unverified, competing
  versions the player has to triangulate themselves, mirroring the district's own established epistemics.
- **Cannot be true:** Gemini cannot have already confirmed and broadcast the complete truth about the
  Lattice. That would make Janbogo too central an authority and directly violate the broader "no single
  source explains the whole picture" rule this mechanic is built on.

### Pisces
- **Must be true:** Pisces has to function as a real physical supply-chain node — salvaged and illicit
  components moving through their existing networks, consistent with their established information-economy
  (not credit-economy) transaction style.
- **Cannot be true:** Pisces cannot be shown as ideologically invested in the Lattice's success or failure
  either way. Their established amorality ("no interest in where you came from... significant interest in
  what you need and what you're willing to trade") means involvement has to stay purely transactional.

### Sagittarius
- **Must be true:** Remote Frostlands outposts already have to operate with some genuine practical
  independence from the central grid, out of frontier necessity rather than ideology — meaning functioning
  proto-Lattice-style local generation already exists here organically. Given Sagittarius's established oral
  storytelling culture (and comparatively weak written institutional record), any breadcrumbs found here
  should be oral/story-based rather than documentary.
- **Cannot be true:** Sagittarius cannot be shown as an organized, citywide political movement pushing the
  Lattice as deliberate ideology. That overstates their established individualist, locally-scoped culture
  into something more centrally coordinated than the lore supports.

### Virgo
- **Must be true:** Virgo is the single most load-bearing district for this entire mechanic. Given their
  established total knowledge of the city's physical infrastructure, their unmapped/undocumented "Deep
  Level" chambers, and their own proven historical precedent for covert leverage against the rest of the
  city (the Year of Silence), Virgo crews have to be the Lattice's primary physical builders and maintainers
  — routed specifically through the Deep Level's uncharted space, which is what lets the Lattice avoid the
  Interdependent Infrastructure Debt problem (genuinely separate, previously-unused space rather than
  entangled with the existing grid). Given Virgo's established meticulous documentation habit, the most
  detailed and technical breadcrumbs in the whole discovery trail should originate here.
- **Cannot be true:** This cannot be an official, sanctioned, department-wide Virgo project, and Virgo cannot
  be shown seeking credit or public acknowledgment for it. Both would contradict their established defining
  pattern — doing the harder, more essential work invisibly, without recognition, exactly as they did during
  the Long Night War itself.

### The Hub (Axis Mundi)
- **Must be true:** The Hub has to be the place where the *old* centralized system's visible failure is most
  directly observable, and is the most plausible site for whatever eventual reckoning or choice moment
  concludes this mechanic, given its established neutral-ground, all-districts-converge role.
- **Cannot be true:** The Hub cannot be where any Lattice infrastructure is actually built, routed, or
  hidden. It's established as the single most watched, most exposed, most politically visible district in
  the city — structurally the worst possible place for concealment of any kind.

## Climax Coalition — flagged 2026-07-21, failsafes needed, not designed yet

**New finding, confirmed by the developer 2026-07-21:** the Aries-as-natural-opponent guideline above (see
Aries's per-district entry) works on a second level once combat is considered. Aries already has an
established identity as the game's toughest, most naturally challenging enemies. In this ending, Aries would
plausibly be fighting alongside Capricorn/Yards leadership (established profit motive to preserve the
status quo — see the Capricorn per-district entry) and Libra/the government (established rationing-authority
motive — see the Libra per-district entry) once the Lattice is discovered and moves against. That's a
three-district coalition converging on the player at the climax, not just Aries alone — plausibly the single
hardest combat encounter in the game.

**Why this matters for design:** a player who did not build their character with this specific fight in
mind, *and* who has not earned Idolized standing with any other district (i.e., has no reputation-based
outside support to call on), could plausibly hit a climax they're mechanically unable to clear. This is a
real difficulty-design risk, not just a narrative one.

**Flagged for future work: failsafes for underprepared/unsupported players.** Not designed yet — no specific
mechanic chosen. Worth considering when this is picked up: alternate resolution paths that don't require
winning a straight fight (consistent with this document's own "cannot be a clean fix" and "cannot require a
single triumphant act" guidelines above — a costly, difficult climax is already the intended shape, but
"very hard" and "mechanically impossible without the right build" are different things and need to stay
distinct); whether reputation with *any* other district (not just Idolized-tier) can grant some form of
assistance, on a sliding scale rather than an all-or-nothing gate; whether the coalition's own three-way
composition (Aries/Capricorn/Libra) can be narratively fractured or partially neutralized through prior
player choices, rather than always arriving as a fixed, undivided bloc. All genuinely open — this section
exists to flag the need, not to answer it.

**Confirmed 2026-07-21 — three specific preparation tasks identified for when this is designed, all still
open, none started:**

1. **Identify which character builds are naturally strong against this specific coalition.** Aries/Capricorn/
   Libra's own established character (Aries: raw endurance/heat-tolerant industrial combat; Capricorn:
   disciplined, precision, industrial-grade equipment; Libra: procedural, defensive, numbers-heavy
   bureaucratic-security backup) should inform what MACHINE stat/skill/perk/trait combination would
   plausibly counter them well — not designed yet, needs an actual pass once the coalition's own combat
   composition is worked out in more detail.
2. **Plan explicit failsafes for every build that ISN'T naturally strong against this coalition.** Once (1)
   identifies the "naturally strong" build(s), the harder and more important task is making sure every other
   viable playstyle still has a real path through this climax — not a watered-down version of the same fight,
   but genuine alternate approaches suited to different builds.
3. **Establish a wide array of actual in-world tools/options usable via (A) skill/stat checks, and (B) player
   creativity/imagination alone** — i.e., not everything should route through a formal mechanical check.
   Given this ending's own established "zero mechanical scaffolding" identity (see the top of this
   document), at least some of the climax's own failsafes should plausibly follow that same spirit — genuine
   environmental/tactical options a clever player can find and use without the game ever telling them it's
   possible, alongside the more conventional stat/skill-gated options for players who'd rather engage that
   way.

None of these three are designed yet — this is a scoping note establishing what actually needs to be figured
out, not the figuring-out itself.
