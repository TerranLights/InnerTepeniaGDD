# Phase 8 — Robot-Specific Culture

> **⚠ Read `00_RUNBOOK.md` first.** It is the mandatory entry point for all district and location
> culture work (binding per the project `CLAUDE.md`), and it opens with **LAW 0 — depth over speed**,
> which governs everything in this file.

**Purpose:** the capstone, and the actual downstream goal this entire plan exists to set up. Robot-Specific
Culture was confirmed 0/13 — zero dedicated headings anywhere across all 13 districts. This is the hard blocker
for the eventual **Local District Robot Culture** work (the direct parallel to the already-complete
`Local_Robot_Culture/` treatment given to all 36 outer-world cities) — but it's blocked *because* the groundwork
isn't there yet, exactly the same dependency that existed for outer cities before their own Local Robot Culture
work began. Do not start this phase for a district until Phases 1-7 are done for that district.

**Read `00b_General_Population_Discipline.md` first.** A narrow robot subtype's culture (one profession, one
institution's staff) is not automatically the district's general robot-population culture — the same check
that caught the Fashion mistakes applies here too, per-robot-population rather than per-human-population.

---

## 1. What this phase actually asks for, and the lens decision it requires

Template §17: *"what robot life and culture looks like within this [location], distinct from the human-robot
dynamic; which sectors robots gravitate toward; philosophical and social character of the robot community
here."*

**The lens decision, finalized here (was left open in the Plan as a one-time decision):** the outer-city version
of this work anchors robot culture in **founding-nation** threads layered onto Robot Universals — a city's
national composition is "which slices of the [robot-culture] pool are locally available to draw from"
(`Local_Robot_Culture_Methodology/00_DRAFT_Input_Categories_and_Approach.md`). Districts aren't nation-founded;
Concordia isn't organized by nationality the way outer Tepenia is. **The district lens is theme/role-based
instead:** a district's own defining civic identity or industry (Cancer's caregiving, Gemini's data work,
Capricorn's industry) is what its robot population organizes its own culture around — the way a workplace or a
calling shapes a subculture, rather than a homeland. This is the direct district-level equivalent of "locality
is dominant" (Robot Universals Ch. 19's own default weighting), just with "locality" cashing out as *district
function* instead of *city/nation*.

---

## 2. Prerequisites

**Hard prerequisite: Phases 1-7 complete for the target district.** This phase draws on every one of them
directly — Architecture/Sensory Profile (where robots physically live/work, what the district feels like to a
robot's senses), Religious/Philosophical Landscape/Fashion (what robots in this district might believe or wear),
Arcanet Culture (network relationship), Ordinary Daily Life (what a robot resident's actual day looks like,
distinct from institutional purpose — directly reusable here), and the Thematic Breadth Catalog (an actual
populated world — places, things, people, settings — for robot culture to embed itself in, rather than a single
thematic landmark repeated in different shapes).

## 3. The adapted methodology — six steps, ported from the outer-city process

This phase should follow the same six-step process already validated for outer cities in
`Local_Robot_Culture_Methodology/00_DRAFT_Input_Categories_and_Approach.md`, with district-specific input
substitutions. Read that file in full before starting — this section only covers what changes for districts.

**Input category substitutions (district equivalents of the outer-city Input Categories A-E):**

| Outer-city input | District equivalent |
|---|---|
| A — National Culture Composition (`Local_Cultures/[City].md`) | District theme/role (Hard Facts "Zodiac / Role") **plus** `District_Refugee_Diaspora_Composition.md`'s weighted feeder-population composition — districts don't have national composition, but they do have a real, weighted population-origin mix that plays a structurally similar role |
| B — Geography & Geology (`Specs/[City].md`) | The color-coded district map (physical scale, Hub-adjacency, gateway status) **plus** Phase 1's own Architecture/Sensory Profile Findings for the target district |
| C — Local Infrastructure (Physical Infrastructure Attributes) | `District_Canon_Reference.md`'s Community Infrastructure section **plus** Phase 6's Thematic Breadth Catalog for that district |
| D — Source Inspirations (`Inspirational-Influences.md`, mandatory translation step) | `District-Inspirational-Influences.md`, same mandatory translation rule: a real-world parallel is never itself a robot custom — always answer "what is the robot-specific analog of this" |
| E — Tepenia-Wide Robot Culture Canon | **Unchanged, applies identically** — Robot Biology and Culture, Glitch-Coolant, Robot Elementals & Solar Symbols, Human-Robot Relations Baseline, the Fragmentation Matrix. Check `city-symbol-pairs.md` for whether districts even participate in the Elements/Solar-Symbol system before assuming they do — this hasn't been confirmed either way for Concordia's districts as of this writing. |

**The six steps, applied per district:**

1. **Concentric-Ring Gathering** — for districts, this ring sequence is largely already built by
   `District_Source_Index.md`: own dedicated files → `District_Canon_Reference.md`/diaspora file →
   cross-district files (`Historical_Inter-District_Effects.md`, `District_Natural_Allies.md`) → repo-wide
   check → sibling districts for contrast → Concordia-wide synthesis (`Concordia_Ultra_Megasheet/`). Use the
   Source Index directly rather than re-gathering from scratch.
2. **Universal-by-Universal Triage** — walk every Robot Universals chapter/universal and every Input Category E
   entry against the target district, into the same four outcomes (Localizes here / Honesty Check null / Out of
   scope / Uncertain). Unchanged from the outer-city process.
3. **Per-Input-Category Pass** — for everything triaged "localizes here," identify the actual local condition
   using the substituted district inputs above. **The Kinship-specific reminder from the outer-city
   methodology applies unchanged:** start from "what is the actual shared experience or shared goal here," not
   from "what's the local mentorship structure" — mentoring is one possible *shape* shared experience takes, not
   a separate mechanism.
4. **Cross-Reference Synthesis** — chase 2nd/3rd/4th-order effects from **combining** input categories, not any
   single one read alone. This is where the most distinctly *local* (as opposed to generic robot-culture)
   findings come from, per the outer-city process's own finding.
5. **Dual Tagging** — every surviving finding gets an Inheritance tag (Directly-inherited pool-draw / Adapted
   pool-draw / Genuinely emergent, district-only) and an Iceberg-layer tag (Surface Culture / Deep Culture),
   unchanged from the outer-city process. Watch for the same failure mode the tags guard against: findings
   clustering entirely in "directly-inherited" or entirely in "Surface Culture" mean the real work hasn't
   happened yet.
6. **The Swap Test** — would this finding still make sense essentially unchanged if the district's name were
   swapped for a demographically/thematically similar neighbor? For districts, the natural swap-test partners
   are districts sharing a similar map position (two small Hub-adjacent wedges) or a similar civic-function
   register (e.g., testing Cancer's findings against Scorpio's, both care/wound-adjacent in different ways) —
   if a finding survives the swap unchanged, it hasn't actually localized to *this* district's theme.

## 7. Rules and pitfalls specific to this phase

- **Don't start this phase for a district whose Phases 1-7 aren't done.** This is a hard, not soft, prerequisite
  — the whole plan's sequencing exists to prevent exactly this mistake.
- **Don't skip the mandatory translation step for Input D.** A real-world Inspirational-Influences parallel is
  never itself a robot custom.
- **Don't let findings cluster in directly-inherited/Surface Culture** — the Dual Tagging step exists
  specifically to catch a district's robot culture reading as "the district's human culture, reskinned."
- **Check `city-symbol-pairs.md` before assuming districts participate in the Robot Elements/Solar Symbol
  system** — unconfirmed as of this writing whether that system extends to Concordia's districts at all.
- **Resolve the output-shape question (§6) before writing, not after.**

## 8. Worked example

**Cancer — `District_Megasheets/01_Cancer/Cancer_Full_Extrapolation.md`, Finding XVII.** *(Corrected
2026-08-29; this section previously read "None yet," which was already false when written.)*

It is the best model available for this phase, and worth reading before starting a new district — **but take
its method, not its content.** Cancer's robot culture organises around care and continuation because that is
Cancer; another district's will organise around something else entirely, and any finding here that could be
lifted onto a different district unchanged has failed Gate 4. What to take from it:

- **The theme/role-based lens applied concretely** — Cancer's robot culture organises around the district's
  defining vocation (care and continuation) rather than around robot-ness as such.
- **Inheritance and Iceberg tagging on every finding** — each is marked *genuinely emergent* / *adapted
  pool-draw* / *mixed*, and placed at Surface or Deep Culture.
- **The Swap Test actually run and reported** — tested against Scorpio, the nearest comparable register, with
  the result stated rather than assumed.
- **An honest scope note** — it states plainly that it was not a full *Robot Universals* triage, rather than
  implying more coverage than it had.
- **Consistency checks against Tepenia-wide canon** — the Human-Robot Relations baseline, the Fragmentation
  Matrix, and one system (Robot Elementals) explicitly left unresolved because the source material had no
  district entries.

Taurus (Finding XIV) and Leo (Finding XIV) also have first-pass Phase 8 material, but neither has been QA'd.
