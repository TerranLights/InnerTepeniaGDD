# Enneagram Reference — Entry Point

**This is the file to link to.** Any character-creation methodology in this repo that needs Enneagram material
— the Stage 1–5 pipeline in `Worldspace/Characters/Dolls/Methodology/`, a companion's own project file, a
future project's own framework — should point back to this `README.md` rather than re-deriving Enneagram theory
locally or linking straight to one of the files below. This page is the map; it doesn't hold the material
itself.

**What's in this folder:** the mined, distilled Enneagram source material this project draws on, kept separate
from any one project's own character-development methodology so it can be reused wherever a Doll's psychology
needs building out. Everything here is distilled into original wording from the source books, not reproduced
verbatim — see each file's own header for provenance.
