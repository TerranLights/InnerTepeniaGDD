# Enneagram Undercurrents

**Status:** established 2026-08-11, developer-originated concept — a structural addition to this project's own
Enneagram framework, not sourced from any of the mined books. Applies project-wide; scoped to Dolls for now,
per the developer's own framing, but not conceptually limited to them.

## What an Undercurrent Is

A doll's main Enneagram Type is the dominant profile that generally drives her — the psychology documented
across `Type_1_The_Reformer/` through `Type_9_The_Peacemaker/`. In addition to that, a doll can optionally
carry a second, weaker Enneagram profile called an **Undercurrent**: a real Type, complete with its own Wing
and Instinctual Subtype, sitting underneath the main Type rather than replacing or blending into it. Think of
it as a secondary personality type — present, real, and occasionally influential, but never load-bearing the
way the main Type is.

## Core Rules

- **Not obligatory.** Only the main Type is required for any character. An Undercurrent exists only where the
  evidence for a real, distinct second signature actually shows up — identified opportunistically, never
  hunted for as a mandatory pass across the roster. No Undercurrent found is a normal, complete state, not a
  gap to flag.
- **Unrestricted by adjacency.** Unlike a Wing (locked to the two types adjacent to the main Type on the
  circle), an Undercurrent can be any of the other eight types.
- **A full profile of its own.** An Undercurrent gets its own Wing and Instinctual Subtype, exactly like a
  proper main-Type assignment — a complete, real Enneagram read, just a weaker one.
- **Relative strength — working baseline 80% Type / 20% Undercurrent.** How much each one actually drives a
  doll's in-character behavior and arc. **Explicitly a placeholder, not a locked mechanic** — if a more
  specific way to model the interplay turns up during actual development (situational triggers, per-scene
  weighting, a stress/security-state-dependent surfacing, anything else that works better in practice), it can
  freely replace the flat split. Use whatever mechanic actually works.
- **Occasional conflict is a feature, not a bug.** The main Type and the Undercurrent can genuinely pull in
  different directions in specific moments — that friction is usable material (an internal contradiction a
  companion questline can dramatize), not something to resolve by permanently picking a winner.
- **Retroactive-eligible.** An Undercurrent can be added after the fact to a doll whose main Type is already
  locked and whose personality is already established, if a genuine second signature is spotted in hindsight.
  This is purely additive — it never reopens or revises the main Type itself.

## How to Identify One

Same rigor as a main-Type read: check the doll's already-established material against a candidate type's
`Core_Psychology.md`/`Subtypes.md` (see `Type_Chapter_Mining_Method.md` for the underlying source-mining
process) for a real, independently-showing-up behavioral signature — just applied opportunistically to a doll
who already has a confirmed main Type, when a second pattern genuinely stands out rather than being
manufactured to hit a quota.

## Recording an Undercurrent

On a doll's own character file, alongside her main Type line:

`Type: [Main Type]w[Wing] [Instinct] · Undercurrent: [Type]w[Wing] [Instinct]`

Same shorthand the roster already uses for a main Type (e.g. `5w6 Social`), appended and clearly labeled —
never presented as if it were the main Type.
