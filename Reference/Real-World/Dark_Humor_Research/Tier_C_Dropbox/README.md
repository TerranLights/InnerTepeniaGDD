# Tier C Dropbox — put fetched files here

Drop anything you fetch from `../Tier_C_Shopping_List.md` into this folder. **Contents are git-ignored** (only this README is tracked).

**Naming (helps, not required):** start the filename with the shopping-list ID, e.g. `C-07_Madsen_2013_thesis.pdf`, `C-21_LOC-VHP_humor_results.html`.
If you forget the ID, any name works; I will match by content.

**Formats that work:** PDF (text or scanned: I can OCR), TXT, HTML ("Save Page As… → Webpage, HTML only" or "Complete"), EPUB, MD, DOCX, images/screenshots (PNG/JPG) of a page or a results list.

**Tips**
- A browser **"Print → Save as PDF"** of a web article is perfect. For long transcripts, save each transcript as its own file.
- For search-driven items (Library of Congress, Imperial War Museum, Texas Tech), the shopping list gives the exact search strings. **Save the results page AND each transcript/record that looks relevant.** A screenshot of the results list is enough for me to tell you which records to pull next.
- If a source turns out to be gone, paywalled for you too, or not worth it, just write one line in `NOTES.txt` here (`C-07: not available`). I will log it as a dead end and stop asking.
- Do not worry about duplicates or messy filenames.

When you have dropped a batch, tell me; I will inventory it, add it to `../source_manifest.csv`, and extract.
